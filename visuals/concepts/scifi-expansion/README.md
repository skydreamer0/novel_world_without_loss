# 《無漏》科幻後期視覺概念

本資料夾整理《無漏》後期由玄幻文明跨入宇宙文明階段的視覺方向，核心維持「天地器官化、界種、文明合成、界力」等既有設定。

## 概念方向

1. **星環祭壇上的秦無漏**：主角進入星際文明階段，東方玄幻服裝語彙與未來裝甲、界力結構結合。
2. **幽冥星門中的生化艦隊**：活體器官與金屬融合的掠奪艦隊，以重力環與高維航道進行星際航行。
3. **破碎天穹下的浮空神域**：呈現天地器官化、界種與文明合成後的世界尺度，以及修行文明與星際艦隊共存的過渡期。

## 後期飛船技術語彙

- 生物機械艦體
- 重力／空間曲率引擎
- 維度航道與星門
- 界力作為高階能源與文明接口
- 艦船可視為可培育、可吞噬、可進化的「文明器官」
