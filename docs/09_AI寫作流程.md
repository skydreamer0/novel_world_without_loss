# AI長篇寫作流程

## 一、規劃層級

長篇內容分成五層：

1. 全書總綱：管理核心命題、終局與五卷因果。
2. 分卷路線圖：管理一百章左右的角色弧線與重大轉折。
3. 章群規劃：每十章形成一個局部問題與階段回報。
4. 單章章卡：管理場景、信息、衝突與章末鉤子。
5. 正文：只執行已確認的當章任務。

## 二、十章批次流程

每次固定處理十章：

1. 先確認該十章的章群問題、階段成果與結束狀態。
2. 將十章逐章細化到場景、情緒轉折、能力代價與章末鉤子。
3. 完成十章正文。
4. 統一檢查時間線、傷勢、人口、資源與伏筆。
5. 更新角色、伏筆、連續性與進度台帳。
6. 同時準備下一批十章細綱。

不得直接依分卷總綱連寫正文。分卷總綱先轉為十章章群，再轉為單章執行細綱。

## 三、單章生成流程

### 第一步：建立開寫包

只載入：

1. 當章章卡。
2. 相關世界規則。
3. 出場角色資料。
4. 上三章摘要。
5. 當前動態狀態。
6. 即將生效的伏筆。

### 第二步：先列場景

每章建議三至五個場景。每個場景必須有：

1. 角色目標。
2. 阻力。
3. 新資訊或狀態變化。
4. 場景結尾的推力。

### 第三步：生成初稿

預設規格：

1. 二千二百至四千二百字，關鍵戰鬥、揭密與卷末章節取高值。
2. 第三人稱限知。
3. 主要視角跟隨秦無漏。
4. 每三百至六百字出現一次局勢變化。
5. 章末留下具體危機、發現或選擇。

### 第四步：四輪校訂

第一輪，情節：

1. 開場是否立刻存在問題。
2. 中段是否有一次認知或權力反轉。
3. 結尾是否改變下一章起點。

第二輪，人物：

1. 每個人是否依自身利益行動。
2. 情緒是否由事件觸發。
3. 反派是否具有合理制度邏輯。

第三輪，設定：

1. 能力條件與代價是否完整。
2. 資源、時間、傷勢是否連續。
3. 是否出現未登記的新名詞。

第四輪，文字：

1. 刪除重複解釋。
2. 減少空泛形容。
3. 將設定說明轉為動作、後果與感官。
4. 對話維持人物差異。

### 第五步：更新台帳

正文定稿後，必須新增：

1. 一百至兩百字章節摘要。
2. 人物狀態變化。
3. 資源與空間變化。
4. 新伏筆與已回收伏筆。
5. 下一章不能遺漏的因果。

## 四、正文風格規範

1. 世界觀透過具體制度和日常損失展現。
2. 爽感來自識破規則、承擔風險與改變天地。
3. 避免連續使用旁白解釋同一概念。
4. 重大設定首次出現時，只交代當前行動必需的部分。
5. 數值只用於殘核、中樞與定額場景，保持其冷硬感。
6. 殘核對話短促，通常不超過兩句。
7. 秦無漏的情緒多由觀察、選擇與身體反應呈現。
8. 居民有自身利益，不因主角救援便立即忠誠。
9. 每次空間成長都配一個可視化景象與一項治理後果。
10. 同類打臉情節不能連續出現，優先使用制度反轉與能力解題。

## 五、AI提示詞骨架

### 寫章提示

請依據《無漏》第X章章卡生成正文。

必須遵守：

1. 只使用提供的設定。
2. 不新增修煉境界、重大人物血緣與世界真相。
3. 本章核心衝突是：〔填寫〕。
4. 本章必須完成：〔填寫三項〕。
5. 本章不可揭露：〔填寫〕。
6. 延續狀態：〔貼入上章摘要與動態狀態〕。
7. 字數：二千二百至四千二百字，依章節功能決定。
8. 視角：第三人稱限知，跟隨秦無漏。
9. 結尾停在：〔填寫章末鉤子〕。

### 審稿提示

檢查本章並分成四類列出問題：

1. 與作品聖經衝突。
2. 人物動機不成立。
3. 情節因果缺口。
4. 節奏與文字冗餘。

每項問題需引用原句、說明後果並提供最小修改方案。不可自行改寫整章。

### 定稿提示

依照已確認的修改清單修訂正文。保留有效場景、對話與章末鉤子。修訂後附上一百至兩百字摘要、狀態變更、伏筆變更與下一章承接點。

## 六、章群檢查

每十章檢查：

1. 主角是否獲得具體成長。
2. 空間是否出現可見變化。
3. 居民是否因成長承受代價。
4. 至少一條人物關係是否改變。
5. 至少一條伏筆是否加深。
6. 是否有一項舊選擇產生後果。
7. 下一個十章問題是否清楚。

每卷完成後檢查：

1. 卷首問題是否回答。
2. 主角的價值觀是否被迫改變。
3. 空間階段是否跨越。
4. 世界觀是否只多揭露一層。
5. 卷末是否創造下一卷無法迴避的局勢。
