# 五卷路線圖

## 第一卷：空胎

章數：第一至七十章

### 卷任務

1. 完成主角從被剝奪者到主動截界者的轉變。
2. 建立空胎、截界、器官化與居民秩序四項核心玩法。
3. 讓復仇帶來第一個道德難題。
4. 讓秦昭從名字變成真實人物。

### 主要事件

1. 開界大典被奪界種。
2. 被診斷為空胎，失去身份、婚約與父親資產。
3. 殘核甦醒。
4. 秦懷忠派人滅口。
5. 第一次截界，吞入破敗邊鎮。
6. 居民認定秦無漏是滅世者。
7. 邊鎮成為第一顆心臟。
8. 救下第一批異族奴工。
9. 記憶雨揭露陰謀片段。
10. 追查、反殺秦懷忠旁支。

### 中段逆轉

秦無漏發現秦懷忠正以旁支人口與土地補繳定額。若直接毀掉旁支，無辜居民會被一併界歸或煉化。

### 卷末選擇與高潮名場面（第65至70章）

1. 秦無漏截走旁支十城殘骸與清河城，保住居民，也讓秦氏永久失去核心資產。他從秦懷忠記憶確認界種配給秦昭的全部檔案。
2. **卷末名場面（合核深處的反擊）**：面對天衡中樞最高等級清收與秦懷忠合界陣的壓迫，秦無漏在忠脈合核底部冷酷掀牌。他揮手召喚出數千半生軀傀儡與離影軍團，站在黑暗空胎邊緣，強行撕裂中樞清收鎖鏈。
3. 無漏之地邊緣誕生第一寸新土並亮起第一道空間極光，秦無漏以「無核空胎」跨階重創合界級陣法，震撼中樞使者晏平章，正式宣示無漏之地的獨立存在。


### 空間結果

一座邊城、若干村落、枯河、初生農田、異族林地與第一座可控界門。人口由數千增至數萬。

## 第二卷：獵界

章數：第七十一至一百八十章

### 卷任務

1. 將被動求生改為主動選擇獵物。
2. 建立文明合成玩法。
3. 讓秦無漏面對「誰有資格被吞噬」。
4. 完成秦無漏與秦昭第一次正面價值衝突。

### 主要事件

1. 偽裝成虛舟盟成員。
2. 進入青崖城地下空間交易。
3. 參加定額拍賣與鬥界台。
4. 吞入劍修宗門，劍意污染農田。
5. 農民與劍修建立耕劍學宮。
6. 萬族牧場暴動。
7. 救出大批異族。
8. 空間人口突破十萬。
9. 秦昭得知界種來源。
10. 秦無漏擊敗秦昭，放棄取回界種。

### 卷末真相

秦無漏確認自己的煉化沒有三成損耗，並首次看見煉化後漂入虛無的殘序潮。

### 空間結果

萬界城、耕劍平原、妖族森林成形。礦山化骨，河流復甦，墓地開始保存死者記憶。

## 第三卷：損耗

章數：第一百八十一至三百章

### 卷任務

1. 揭露上一紀元。
2. 把秦無漏的優勢變成中樞必須掌控的戰略資源。
3. 讓界力借債造成不可逆失敗。
4. 讓居民從受保護者成為政治主體。

### 主要事件

1. 加入虛舟盟遠征。
2. 發現上一紀元遺界。
3. 取得第二枚殘核碎片。
4. 得知損耗真相與殘核身份。
5. 中樞邀請合作並要求交出無漏能力。
6. 秦無漏拒絕。
7. 中樞封鎖萬界城外部資源。
8. 第一批界生者誕生。
9. 秦無漏向未來百年借力。
10. 擊退中樞軍後，天地全面衰退。

### 重大失敗

農田枯竭、居民衰老、城市叛亂。第二次清算中萬界城破，大量居民死亡並化為山脈、河流與墓園。

### 卷末認知

界主調用的力量都有具體承擔者。秦無漏過去視為數值的界力，實際是居民未來的糧食、壽命、記憶與選擇。

## 第四卷：逆流

章數：第三百零一至四百三十章

### 卷任務

1. 重建萬界城並建立無漏之地。
2. 從個人治理走向自治制度。
3. 全面展開文明融合。
4. 完成秦無漏與殘核的價值決裂。

### 主要事件

1. 空胎者投奔。
2. 被圈養異族全面起義。
3. 城市取得自治權。
4. 秦昭率秦氏殘部加入。
5. 舊世家後人進入無漏之地。
6. 活體城市、液態文字、死後醫學相繼誕生。
7. 界生者建立議會。
8. 界生者反對秦無漏永久統治。
9. 殘核恢復完整記憶。
10. 秦無漏將界圖權限分散。

### 卷末局勢

無漏之地脫離天衡中樞。中樞動員整個界域進行最終圍剿。

## 第五卷：開天

章數：第四百三十一章至完結

### 卷任務

1. 讓四條救世界道路正面碰撞。
2. 揭露天衡界域也處於他人天地內。
3. 完成新生能力。
4. 解決創造者與統治權的矛盾。

### 主要事件

1. 中樞啟動唯一大界。
2. 弱小界域被強制融合。
3. 秦無漏進入中樞核心。
4. 上層世界準備煉化整個下層界域。
5. 天衡首座提出合作。
6. 殘核奪取部分界圖權限。
7. 秦無漏與殘核決裂。
8. 各族各城共同創造新界律。
9. 第一方全新天地誕生。
10. 秦無漏交出永久控制權。

### 最終畫面

秦無漏站在界外回望。文明燈火沿天地經脈蔓延，死者化作山川、星辰、道路與記憶。那片天地能自行呼吸、生長與選擇未來。

## 全書節奏

### 每三至五章

1. 新土地、資源或人口。
2. 一次空間異常或器官變化。
3. 一項角色關係改變。
4. 一個可見的收益與代價。

### 每十五至二十章

1. 越級戰鬥或大型危機。
2. 一次大型截界。
3. 新生城市、制度、職業或法則。
4. 解決一項重大法則衝突。

### 每五十章

1. 主角身份跨越。
2. 空間器官完成進化。
3. 文明規模提升。
4. 世界真相揭露一層。
5. 舊選擇的代價集中爆發。
