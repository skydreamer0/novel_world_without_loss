# 《無漏》總綱與核心命題

## 一句話故事

被奪走界種、淪為空胎的秦無漏，靠吞下他人遺失的天地求生，最終發現世界也能從眾生創造的新關係、新制度與新文明中誕生。

## 核心命題

這個世界沒有真正的創造。

修士的成長建立在吞噬既有天地之上。每一次煉化，都會讓部分空間失去座標、秩序與法則，沉入虛無。文明越繁榮，世界消失得越快。

秦無漏的道路分成三次認知轉變：

1. 前期：天地是他活下去與復仇的資源。
2. 中期：天地中的眾生承擔界主使用力量的代價。
3. 後期：天地的成長來自眾生建立的新關係，界主只是其中一名參與者。

## 故事承諾

1. 空間養成具有可視化變化，土地、城市與文明會留下永久痕跡。
2. 每次力量提升都會改變空間內居民的生活。
3. 吞噬能帶來即時爽感，也會製造倫理、政治與生態後果。
4. 主角與秦昭、天衡首座、殘核分別代表四條救世界的道路。
5. 終局答案會由前期的居民秩序、文明合成、界生者與空間自治逐步推導出來。

## 四條道路

| 人物 | 方法 | 優點 | 結構性代價 |
|---|---|---|---|
| 秦無漏 | 回收損耗，促成新文明 | 能開啟真正增量 | 必須放棄永久控制 |
| 秦昭 | 維持家族與中樞秩序 | 短期穩定，可保護熟悉的人 | 持續把代價轉嫁給弱者 |
| 天衡首座 | 犧牲多數，建成唯一大界 | 能延長文明壽命 | 多樣性消失，法則停滯 |
| 殘核 | 完全合界，精確管理 | 損耗最低，效率最高 | 眾生被視為可計算材料 |

## 主角外在目標

1. 找出界種被奪的真相。
2. 在家族追殺下活下來。
3. 建立能承載居民的穩定天地。
4. 擺脫天衡中樞的資源封鎖。
5. 阻止唯一大界計畫與上層煉化。

## 主角內在缺陷

秦無漏早年被當作未來界主培養，習慣把能力、秩序與責任集中在自己身上。遭背叛後，他更加相信只有掌控一切才能避免再次失去。

他的成長核心：

1. 接納自己無法控制文明合成。
2. 承認居民具有拒絕他的權利。
3. 把界圖與天地權限交給不同城市與族群。
4. 在終局放棄成為新中樞。

## 全書終局

新天地的來源包括：

1. 從虛無收回的虛質。
2. 重新整理的殘序。
3. 文明融合產生的新法則。
4. 界生者誕生帶來的新座標。
5. 居民共同認可的天地秩序。

秦無漏交出天地的永久控制權。無漏之地成為第一個能自行呼吸、生長與選擇未來的世界。

## 終局判準

結局成立前，正文必須逐步證明五件事：

1. 秩序能產生界力。
2. 新關係能形成既有世界沒有的法則。
3. 界生者具有獨立座標。
4. 多中心治理比唯一意志更能維持文明活性。
5. 秦無漏願意接受一個無法完全服從他的世界。
