# 空間與力量系統

## 一、無漏能力三階段

### 收攏

回收煉化散逸的虛質、殘序與小型遺界。

前期限制：

1. 需要靠近損耗發生地。
2. 回收物仍混亂，不能直接使用。
3. 大量殘序會造成夢境、錯誤記憶與認知污染。

### 重組

將破碎法則、功法與文明資訊重新排列。

中期限制：

1. 重組結果受現有居民、制度與環境影響。
2. 只能提高成功可能，不能指定唯一結果。
3. 錯誤重組會生成法則疾病或異常區域。

### 新生

眾生建立的新關係產生新法則，新法則生成全新座標與空間。

完成條件：

1. 文明具有多樣性。
2. 居民具有真實選擇權。
3. 新秩序獲得共同認可。
4. 界生者能在沒有外界來源的情況下誕生。
5. 秦無漏放棄對所有法則的單方控制。

## 二、殘核五項能力

### 解析

看見界壁弱點、法則衝突、空間結構與界歸通道。資訊越複雜，解析耗時越長。秦無漏早期只能看見局部結構。

### 截界

條件：

1. 接觸目標的血、界力或核心法則。
2. 找到界壁弱點。
3. 在界歸完成前攻破界門。

失敗後果包括界歸反噬、空胎暴露、殘序污染與被歸屬勢力鎖定。

選擇性截界限制：

1. 目標區域必須擁有可單獨定位的子界門。
2. 秦無漏必須解析子界門與主界之間的全部牽引線。
3. 被選區域內的生命錨、爆界陣與強制契約需先解除。
4. 截取本身可以無損，戰鬥與解除契約造成的死亡仍無法逆轉。
5. 每多切分一層結構，所需操作精度與殘核負荷都會提高。

### 奪取

空間進入空胎後依序經過：

1. 收錄。
2. 解析。
3. 適配。
4. 融合。

高階傳承可能帶有意志污染、法則陷阱與原主殘念。吞入只代表取得，不能等同掌握。

### 推演

消耗虛質與殘序，進行功法推演、戰局預測、禁制破解與文明模擬。

推演輸出必須表現為機率、分支或風險，不可成為全知答案。

### 界圖

顯示：

1. 法則穩定度。
2. 文明活性。
3. 居民認同。
4. 虛無侵蝕。
5. 土地器官狀態。
6. 區域衝突。
7. 新生法則。
8. 未知異變。

界圖早期資訊殘缺，並可能受到居民認知、殘序污染與殘核立場影響。

界圖已觀測到兩種不依賴界核授權的新座標來源：

1. 居民共同承認的新名冊，可讓原本沒有登記的人取得穩定座標。
2. 多方自願遵守的公共契約，可生成低階界律雛形。

這兩種現象只能透過持續實踐維持。單方面命令或強制簽署無法產生同等效果。

界圖已確認第三種授權形式：

3. 外部城市居民可透過公開表決與臨時契約，把城市心臟的限時使用權交給秦無漏。此授權不轉移土地歸屬，也不使城市自動進入空胎。

外部借力限制：

1. 必須由城市現有居民依可驗證程序共同授權。
2. 權限只在約定時間與用途內有效。
3. 城市自行承擔疲勞、界壁下降與後續資源缺口。
4. 秦無漏可以拒絕接收土地，單獨切斷強制契約。
5. 授權一旦到期，殘核不得保留城市控制權。

### 多節點分段協同

不同城市、聚落與天地器官可以各自授予限時權限，形成多條彼此獨立的界力通道。

1. 每條通道保留自己的用途、期限與撤回方式。
2. 秦無漏只能協調，不能把分段權限永久熔成界核。
3. 任一節點撤回時，其他節點需要自行決定是否補位。
4. 分段協同的即時效率低於單一核心，能避免一處權限被奪便控制全部節點。
5. 七息守城首次證明多個自治節點可以在保留衝突與撤回權的情況下抵抗中樞接管。

### 離影異常

空胎的第二次大規模異常會使居民影子脫離，重演本體曾想過卻沒有實行的選擇。

1. 強行磨滅離影可以終止危機，也會磨去本體對相關選擇的部分認知。
2. 完成一輪未竟選擇後，多數影子可由本體自願接納。
3. 拒絕回歸且能維持自我認知的影子，可以在公共名冊、獨立錨點與居民承認下取得座標。
4. 取得座標的影子屬於異常生命，不能直接視為界生者。
5. 遲影的自我命名已使界圖出現「自我命名」未知法則，後續仍需檢驗其權利與污染風險。

### 無核錨點

空胎者進入沒有座標的空洞後，可以用自身缺失承接局部「無座標」狀態，使周圍土地獲得暫時穩定。

限制：

1. 無核錨點不會產生土地與界力。
2. 空胎者必須自願進入，秦無漏不得把其界胚當作借力區域。
3. 名字、關係與他人持續承認可降低身份被覆寫的風險。
4. 錨定時間越長，越可能失去記憶、方向與個人座標。
5. 多名空胎者可以提高穩定度，也會讓法則污染在彼此之間傳遞。

## 三、天地器官化

| 地貌 | 器官功能 | 過量或失衡 |
|---|---|---|
| 城市 | 心臟，人口流動形成界力循環 | 城市過密導致界力心衰 |
| 河流 | 經脈，運輸資源與法則 | 河道衝突造成法則逆流 |
| 礦山 | 骨骼，提高界壁強度 | 礦山過多導致天地骨化 |
| 森林 | 肺，吸收虛無與污染 | 過度擴張吞噬城市與農地 |
| 墓地 | 記憶器官，保存死者經驗 | 殘念累積造成記憶瘟疫 |
| 學宮 | 神經節點，促進推演與交流 | 單一學派壟斷造成法則僵化 |
| 農田 | 消化與代謝，將資源轉成生命循環 | 過度借力造成長期荒蕪 |
| 界門 | 感官與關節，連接區域及外界 | 開啟過多造成座標失血 |

器官化是長期適配結果，不應在吞入後立刻完成。正文需要呈現前兆、衝突、成形與後遺症。

## 四、文明合成

| 組合 | 可能成果 | 潛在衝突 |
|---|---|---|
| 劍修與農民 | 耕劍文明 | 農田被劍意切割 |
| 亡靈與醫者 | 死後醫學 | 死者同意與記憶所有權 |
| 妖族與機關師 | 血肉機械 | 身體改造與族群純化 |
| 水族與書院 | 液態文字 | 知識只能在流動中保存 |
| 商人與夢境族 | 記憶交易 | 人格與記憶成為商品 |
| 蟲族與建築師 | 活體城市 | 城市是否具有人格 |

文明成果必須經歷：

1. 接觸。
2. 摩擦。
3. 危機。
4. 妥協或共同需求。
5. 新生職業、制度或法則。
6. 反作用。

## 五、界力借債

| 借用來源 | 即時效果 | 長期代價 |
|---|---|---|
| 農田 | 恢復力提升 | 未來收成下降 |
| 城市 | 戰力與界術增幅 | 居民集體疲憊 |
| 墓地 | 調用死者經驗 | 喚醒殘念 |
| 森林 | 解毒、隱匿、再生 | 森林吸入污染後異變 |
| 礦山 | 強化肉身與防禦 | 界壁僵化、地脈斷裂 |
| 未來 | 提前使用多年界力 | 衰退、老化、停滯與政治危機 |

借債必須記錄四個數字：

1. 借用區域。
2. 借用量。
3. 償還期限。
4. 已顯現後果。

## 六、死者化界

重要居民死亡後，其一生最強烈的道路會融入天地。

1. 將軍可能化為山脈。
2. 學者可能化為藏書樓。
3. 航海者可能化為河流。
4. 暴君可能化為災區。

死者化界需要具備足夠的居民認同、人生軌跡與天地連結。普通死亡只留下微弱殘序，避免每名死者都造成地貌膨脹。

## 七、界生者

當空間內誕生外界沒有的新法則、文化與關係時，可能出現沒有父母與外界來源的生命。

界生者的故事功能：

1. 證明天地可以產生新增量。
2. 具備秦無漏也無法完全解析的新法則。
3. 天然屬於無漏之地，不欠秦無漏救命或收容之恩。
4. 推動「創造者是否有永久統治權」的政治衝突。

## 八、世界異常

可用事件庫：

1. 天空降下記憶雨。
2. 所有影子獲得獨立意識。
3. 月亮墜落成為遺跡。
4. 河流開始流向過去。
5. 某座城市從界圖消失。
6. 新生兒說著上一紀元的語言。
7. 全界一日無法說謊。
8. 死者在夢中建立第二座城市。

異常需要至少承擔兩項功能：

1. 製造當前危機。
2. 帶來新資源。
3. 揭露歷史。
4. 改變角色關係。
5. 推動文明合成。

## 十、空間戰力與修煉境界分級

天衡界域以「空間規模與法則掌握」劃分修士戰力體系，共有六大階段：

1. **觀界（微感）**：感應體內界胚與天地座標，調用微弱界力強化肉身與法器。
2. **撐界（初界）**：開界成功，撐開十里至百里初界，固定1-2座邊城，界壁初步成形。
3. **拓界（器官）**：空間突破百里，形成河流、礦山、森林等天地器官，可調用多器官界力連動。
4. **掌界（城域）**：控制十城至數百里天地，形成完整界力循環與法則生態，可獨立禦敵。
5. **化界（領域）**：山河法則與自身神魂融合，能進行選擇性截界與法則選擇性吞噬。
6. **合界（大界）**：將多個大城與萬里天地壓成唯一核心（中樞巨頭級），界力浩瀚但損耗極劇。

**秦無漏的特殊定位——「無核空胎」**：
秦無漏無界核、無固定等級上限。他不受常規境界瓶頸限制，但戰力完全取決於「局部錨點數量、器官適配度、生靈名冊與冷血手段的調用精度」。他能以空胎特性跨階截殺高階掌界者或化界強者。


## 十一、極致主導與法則漏洞（冷血手段庫）

秦無漏堅持「不強制煉化活人生靈」的名義底線，但為了生存、對抗中樞與極致爆發界力，他利用規則漏洞開發了五種冷血手段：

1. **半生軀 / 虛質傀儡**：利用回收的虛質與黑砂拼接無靈魂、無戶籍的血肉軀殼。無痛覺、無意識，作為高危工兵與自爆戰具。
2. **離影剝奪 / 惡念徭役**：割離叛逆者或俘虜的影子與惡念，煉成無休止勞作的「離影衛」。本體存活但呆滯，影子充當永動機。
3. **殘序織生 / 墓園兵工廠**：回收墓地器官中的死者殘序與礦石融合，編織血肉機關獸。冷酷計算強者戰死的殘序價值，進行「合法收屍」。
4. **壽元租賃契**：以生存庇護、功法為條件讓生靈簽署壽元抵押契。急需界力時冷酷啟動，依約抽取數十年壽元。
5. **蜉蝣胎殼 / 七日暴兵工廠**：將敵人失魂肉身作為培養皿，孵化七日短命蜉蝣族。一周內完成繁衍、爆發界力與衰亡肥料化。
