# 空間與力量系統

## 一、無漏能力三階段

### 收攏

回收煉化散逸的虛質、殘序與小型遺界。

前期限制：

1. 需要靠近損耗發生地。
2. 回收物仍混亂，不能直接使用。
3. 大量殘序會造成夢境、錯誤記憶與認知污染。

### 重組

將破碎法則、功法與文明資訊重新排列。

中期限制：

1. 重組結果受現有居民、制度與環境影響。
2. 只能提高成功可能，不能指定唯一結果。
3. 錯誤重組會生成法則疾病或異常區域。

### 新生

眾生建立的新關係產生新法則，新法則生成全新座標與空間。

完成條件：

1. 文明具有多樣性。
2. 居民具有真實選擇權。
3. 新秩序獲得共同認可。
4. 界生者能在沒有外界來源的情況下誕生。
5. 秦無漏放棄對所有法則的單方控制。

## 二、殘核五項能力

### 解析

看見界壁弱點、法則衝突、空間結構與界歸通道。資訊越複雜，解析耗時越長。秦無漏早期只能看見局部結構。

### 截界

條件：

1. 接觸目標的血、界力或核心法則。
2. 找到界壁弱點。
3. 在界歸完成前攻破界門。

失敗後果包括界歸反噬、空胎暴露、殘序污染與被歸屬勢力鎖定。

選擇性截界限制：

1. 目標區域必須擁有可單獨定位的子界門。
2. 秦無漏必須解析子界門與主界之間的全部牽引線。
3. 被選區域內的生命錨、爆界陣與強制契約需先解除。
4. 截取本身可以無損，戰鬥與解除契約造成的死亡仍無法逆轉。
5. 每多切分一層結構，所需操作精度與殘核負荷都會提高。

### 奪取

空間進入空胎後依序經過：

1. 收錄。
2. 解析。
3. 適配。
4. 融合。

高階傳承可能帶有意志污染、法則陷阱與原主殘念。吞入只代表取得，不能等同掌握。

### 推演

消耗虛質與殘序，進行功法推演、戰局預測、禁制破解與文明模擬。

推演輸出必須表現為機率、分支或風險，不可成為全知答案。

### 界圖

顯示：

1. 法則穩定度。
2. 文明活性。
3. 居民認同。
4. 虛無侵蝕。
5. 土地器官狀態。
6. 區域衝突。
7. 新生法則。
8. 未知異變。

界圖早期資訊殘缺，並可能受到居民認知、殘序污染與殘核立場影響。

界圖已觀測到兩種不依賴界核授權的新座標來源：

1. 居民共同承認的新名冊，可讓原本沒有登記的人取得穩定座標。
2. 多方自願遵守的公共契約，可生成低階界律雛形。

這兩種現象只能透過持續實踐維持。單方面命令或強制簽署無法產生同等效果。

界圖已確認第三種授權形式：

3. 外部城市居民可透過公開表決與臨時契約，把城市心臟的限時使用權交給秦無漏。此授權不轉移土地歸屬，也不使城市自動進入空胎。

外部借力限制：

1. 必須由城市現有居民依可驗證程序共同授權。
2. 權限只在約定時間與用途內有效。
3. 城市自行承擔疲勞、界壁下降與後續資源缺口。
4. 秦無漏可以拒絕接收土地，單獨切斷強制契約。
5. 授權一旦到期，殘核不得保留城市控制權。
6. 緊急狀態不會自動延長舊授權。若需在新戰事中重新調用，必須再次確認用途、期限、預估代價與撤回方式。
7. 授權區域可限定界力只用於識別、避難、防禦或特定目標；秦無漏不得把限定用途轉為殺傷性戰力。

### 多節點分段協同

不同城市、聚落與天地器官可以各自授予限時權限，形成多條彼此獨立的界力通道。

1. 每條通道保留自己的用途、期限與撤回方式。
2. 秦無漏只能協調，不能把分段權限永久熔成界核。
3. 任一節點撤回時，其他節點需要自行決定是否補位。
4. 分段協同的即時效率低於單一核心，能避免一處權限被奪便控制全部節點。
5. 七息守城首次證明多個自治節點可以在保留衝突與撤回權的情況下抵抗中樞接管。

### 離影異常

空胎的第二次大規模異常會使居民影子脫離，重演本體曾想過卻沒有實行的選擇。

1. 強行磨滅離影可以終止危機，也會磨去本體對相關選擇的部分認知。
2. 完成一輪未竟選擇後，多數影子可由本體自願接納。
3. 拒絕回歸且能維持自我認知的影子，可以在公共名冊、獨立錨點與居民承認下取得座標。
4. 取得座標的影子屬於異常生命，不能直接視為界生者。
5. 遲影的自我命名已使界圖出現「自我命名」未知法則，後續仍需檢驗其權利與污染風險。

### 無核錨點

空胎者進入沒有座標的空洞後，可以用自身缺失承接局部「無座標」狀態，使周圍土地獲得暫時穩定。

限制：

1. 無核錨點不會產生土地與界力。
2. 空胎者必須自願進入，秦無漏不得把其界胚當作借力區域。
3. 名字、關係與他人持續承認可降低身份被覆寫的風險。
4. 錨定時間越長，越可能失去記憶、方向與個人座標。
5. 多名空胎者可以提高穩定度，也會讓法則污染在彼此之間傳遞。

## 三、天地器官化

| 地貌 | 器官功能 | 過量或失衡 |
|---|---|---|
| 城市 | 心臟，人口流動形成界力循環 | 城市過密導致界力心衰 |
| 河流 | 經脈，運輸資源與法則 | 河道衝突造成法則逆流 |
| 礦山 | 骨骼，提高界壁強度 | 礦山過多導致天地骨化 |
| 森林 | 肺，吸收虛無與污染 | 過度擴張吞噬城市與農地 |
| 墓地 | 記憶器官，保存死者經驗 | 殘念累積造成記憶瘟疫 |
| 學宮 | 神經節點，促進推演與交流 | 單一學派壟斷造成法則僵化 |
| 農田 | 消化與代謝，將資源轉成生命循環 | 過度借力造成長期荒蕪 |
| 界門 | 感官與關節，連接區域及外界 | 開啟過多造成座標失血 |

器官化是長期適配結果，不應在吞入後立刻完成。正文需要呈現前兆、衝突、成形與後遺症。

| 亡靈與醫者 | 死後醫學 | 死者同意與記憶所有權 |

文明成果必須經歷：

1. 接觸。
2. 摩擦。
3. 危機。
4. 妥協或共同需求。
5. 新生職業、制度或法則。
6. 反作用。

|---|---|---|

## 六、死者化界

重要居民死亡後，其一生最強烈的道路會融入天地。

1. 將軍可能化為山脈。
2. 學者可能化為藏書樓。
3. 航海者可能化為河流。
4. 暴君可能化為災區。

死者化界需要具備足夠的居民認同、人生軌跡與天地連結。普通死亡只留下微弱殘序，避免每名死者都造成地貌膨脹。

## 七、界生者

當空間內誕生外界沒有的新法則、文化與關係時，可能出現沒有父母與外界來源的生命。

界生者的故事功能：

1. 證明天地可以產生新增量。
2. 具備秦無漏也無法完全解析的新法則。
3. 天然屬於無漏之地，不欠秦無漏救命或收容之恩。
4. 推動「創造者是否有永久統治權」的政治衝突。

## 八、世界異常

可用事件庫：

1. 天空降下記憶雨。
2. 所有影子獲得獨立意識。
3. 月亮墜落成為遺跡。
4. 河流開始流向過去。
5. 某座城市從界圖消失。
6. 新生兒說著上一紀元的語言。
7. 全界一日無法說謊。
8. 死者在夢中建立第二座城市。

異常需要至少承擔兩項功能：

1. 製造當前危機。
2. 帶來新資源。
3. 揭露歷史。
4. 改變角色關係。
5. 推動文明合成。

## 九、天地界格

界格描述一方天地的結構與文明成熟度，不等同於界主修為。高階修士可以擁有殘破低格天地，低階修士也可能因繼承、界種或截界持有超出自身控制能力的高格資產。

| 階段 | 外觀 | 核心能力 | 主要危機 |
|---|---|---|---|
| 荒界 | 黑暗中一座孤城 | 固定局部錨點 | 糧食、恐慌、居民敵意 |
| 城界 | 多城與河網亮起 | 形成界力循環 | 器官失衡 |
| 國界 | 多文明共存 | 新生職業與混合法則 | 制度衝突 |
| 活界 | 天地器官完整 | 空間產生模糊意志 | 界主失去部分控制 |
| 眾生界 | 界生者與自治議會出現 | 共同制定界律 | 統治合法性 |
| 新天 | 世界可自行生長 | 新生座標與空間 | 面對上層煉化 |

## 十、空間戰力與修煉境界分級

### 三軸評級

天衡界域不以土地里數直接判定修為。完整戰力由三項資料共同描述：

1. **界階**：修士掌握哪一層空間權限，決定「能做什麼」。
2. **界格**：內天地的結構、器官與文明成熟度，沿用荒界至新天的分類。
3. **界勢**：當下可安全輸出的力量，受所在位置、界傷、居民授權、法則相性與界力借債影響。

土地面積、人口與資源只代表界藏及潛力，不會自動使修士破境。百里極品初界仍可屬撐界初成；三十六里殘破天地也可能由撐界圓滿者持有。

界階共分六境，每境再以「初成、成環、圓滿」表示穩定程度：

| 界階 | 空間質變 | 標誌性戰鬥權限 | 晉升核心 | 主要失控 |
|---|---|---|---|---|
| **觀界** | 感應界胚、座標與法則 | **引界**：引微弱界力入體、辨認法則 | 找到自身座標並具備承種能力 | 感知錯位、肉身界化 |
| **撐界** | 形成界核、界壁與界門 | **顯相**：投影一種地貌或法則，如石甲、劍丘 | 建立第一個不依賴外力維持的界力循環 | 界壁重疊、界核裂紋 |
| **拓界** | 河流、礦山、森林等器官連動 | **聯器**：同時調用多種天地器官組成界術 | 至少三類器官形成可持續閉環 | 器官失衡、天地骨化或心衰 |
| **掌界** | 天地能短暫脫離界主命令自行運轉 | **展域**：使局部外界服從內天地秩序 | 城市與器官在無直接命令下完成一次完整循環 | 界域反噬、居民與界主感知混淆 |
| **化界** | 凝成一條與神魂相合的主律 | **行律**：選擇性截界、禁用或改寫一條局部規則 | 主律經歷異質文明或法則衝突仍不崩潰 | 性情律化、神魂被天地反向同化 |
| **合界** | 多條主律構成可自洽的大界體系 | **天覆**：讓大範圍內天地降臨現實 | 調和至少三種互斥主律並維持完整循環 | 法則互吞、文明被單一主律抹除 |

越階對抗必須符合以下硬規則：

1. 正面狀態下最多跨越一個界階，且必須具備結構克制、主場、外部授權或等價界債。
2. 跨越兩階只可能發生在對手重傷、陣法存在死穴或多方天地共同借力時，不能視為常態戰力。
3. 高一階權限具有自然壓制。低階者若未先破解其界核、器官、界域或主律，單純增加界力量無法擊穿。
4. 越階代價必須落到具體器官、土地、居民或神魂，並在後續章節持續存在。

### 合界雙路

「合界」是修為結果，不限定只能壓成唯一核心。天衡文明已知兩種方向：

1. **一核合界法**：刪除互斥法則，將萬城與眾生壓入唯一核心。成形快、調度強、短期穩定，代價是高損耗、文明同質化與單點崩潰。
2. **眾律合界法**：各城市與族群保留局部法則、否決及退出權，以持續履行的聯約維持整體。即時效率較低，卻能保留差異、分散故障並形成新法則。此路在前期尚未被正式承認，由秦無漏的自治節點逐步證明。

天衡界域公開認知以合界為修煉頂點。「不再吞噬既有天地，反而產生新座標」屬於尚未被證實的下一步，終局可命名為**開天**。

### 秦無漏：體制外異類

秦無漏沒有界核，不能被登記為觀界至合界中的任何一境，也不會在中途補上一個傳統境界。他的進度只以「無核六證」追蹤：

| 無核之證 | 成立判準 | 對應進展 |
|---|---|---|
| **定錨** | 土地能在無全域邊界的空胎中取得穩定座標 | 沉河城成為第一顆心臟 |
| **成環** | 兩種以上天地器官形成可維持的局部循環 | 城市、母根與黑礦開始交換界力 |
| **織網** | 多個自治節點能保留撤回權並協同借力 | 七息守城、三城聯約 |
| **立律** | 不依賴界核命令的公共規則獲得法則效力 | 居民契約、名冊與記憶糧契 |
| **生界** | 產生沒有外界轉移來源的新座標、土地或生命 | 第一寸新土只構成初證，尚不能穩定運用 |
| **開天** | 天地脫離秦無漏的單方控制仍可自行生長 | 全書終局判準 |

無核六證不是六個可逐級儲力的境界。秦無漏只能透過已有錨點、器官、聯約與新生法則，短暫模擬相應的高階權限；通道中斷後立即失去。第一卷重創合界陣，代表他以死穴、多城授權與全界借債短暫觸及高階權限，不代表常態戰力等同合界。


## 十一、禁忌方案與主體性紅線

以下手段來自殘核或上一紀元資料，不等於秦無漏已掌握、已接受或可無代價使用。它們的故事功能是測試「什麼才算一個人」，並暴露殘核將生命轉成效率單位的價值觀。

1. **半生軀 / 虛質傀儡**：以回收虛質、黑砂與無主殘序拼成的空殼。製造必須記錄材料、數量、工時與墓地污染；禁忌權限只能提供啟動方法，不能憑空生成軍隊。一旦出現痛覺、恐懼、自我命名或持續意圖，必須立即停用並依潛在生命登記。
2. **離影剝奪 / 惡念徭役**：割離活人影子、人格或惡念進行強制勞役，會同時傷害本體與離影的主體性，屬明確禁術。離影只能在知情、可拒絕、可中途退出的情況下提供協助。
3. **殘序織生 / 墓園兵工廠**：死者殘序可用於識別、導航、紀念與保護，但不得未經死者預留意願或墓地公共規則便武器化。將殘序當作無主材料，會導致記憶瘟疫與名籍拒絕。
4. **壽元租賃契**：高度剥削風險的契約。必須有獨立見證、充分知情、無即時生存脅迫、明確上限與撤銷機制；否則無法產生有效公共契律。
5. **蜉蝣胎殼 / 七日暴兵工廠**：以失魂肉身培育短命生命，涉及肉身同意、新生命自主性與刻意製造短命種族，為殘核可能提案，不屬無漏之地合法戰力。
