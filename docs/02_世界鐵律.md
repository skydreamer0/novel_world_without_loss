# 世界鐵律

本檔內容屬於強制設定。正文若需要例外，必須先寫出代價與來源，再更新作品聖經。

## 一、界胚

人人出生時，體內都有一枚尚未成形的界胚。界胚沒有土地與容積，只代表一個可被開啟的可能。

十六至十八歲之間，每人只能參加一次正式開界儀式。開界需要：

1. 開界資質：承受界種與界核形成的身體、神魂條件。
2. 空間資源：撐開第一層界壁所需的原料與能量。
3. 界種契機：提供初始座標、法則傾向與界核雛形。

三者缺一不可。儀式一旦啟動，界胚便會留下永久變化。

## 二、開界

界種進入界胚後形成界核。界核固定座標、撐開邊界，讓初界誕生。

界核決定四項基礎：

1. 初始面積。
2. 界壁強度。
3. 法則相性。
4. 未來承載上限。

正常修士的天地都有邊界。吞噬超過界核承載能力時，先出現界壁重疊、法則衝突與界核裂紋，最終導致天地崩塌。

## 三、空胎

秦無漏的界種在開界途中被奪走。他的界胚已被撐開，界核卻沒有形成，留下有入口、無全域邊界、無固定座標的空胎。

空胎特性：

1. 無法自行生成土地。
2. 初期無法在秦無漏體內儲存個人界力。
3. 無法依靠界核穩定生命與法則。
4. 沒有可測量的全域承載上限。
5. 吞入的土地必須先形成局部錨點，才能在黑暗中固定。

「無邊界」指空胎沒有一圈完整外壁。每塊被吞入的土地仍會形成局部界壁與座標。多個錨點連接後，才逐步形成可居住天地。

空胎者因缺少界核與固定座標，比正常開界者更能承受虛無及無座標區域。他們無法因此自動辨認方向，也不能直接產生界力。長期作為虛無活錨會引發身份覆寫、記憶缺失與座標消退。

## 四、界力

界力來自土地、法則、生命與秩序的循環。

一般修士透過界核儲存、提煉與輸出界力。秦無漏沒有界核，前期只能讓界力在已錨定區域內流動，再透過殘核建立臨時通道借用。

這項設定解決兩個限制：

1. 秦無漏仍屬空胎，不能像正常修士長期儲力。
2. 空間居民恢復生產後，天地可以產生微弱界力供他短暫調用。

## 五、煉化損耗

奪取外界空間時，約三成內容會在轉移中失去座標與秩序，沉入虛無。

損耗分成：

| 類別 | 定義 | 常見表現 |
|---|---|---|
| 虛質 | 失去秩序的空間原料 | 黑砂、無向水、無重之土 |
| 殘序 | 破碎的法則、功法、記憶與文明資訊 | 重複語句、斷裂招式、錯位歷史 |
| 遺界 | 尚未完全磨滅的文明殘骸 | 漂流城、斷裂山河、無主界門 |

現有文明無法穩定利用三者，因此將其視為永久消失。

秦無漏的無漏之體能保住正常煉化會散逸的部分，也能從虛無重新收攏舊損耗。回收量受接觸範圍、解析能力與空間穩定度限制。

## 六、界歸

開界者死亡後，其空間會依預設契約回歸家族祖界、宗門界碑或中樞界庫。回歸內容包含土地、人口、資源與可被保留的法則。

界歸具有四個階段：

1. 死亡確認。
2. 界門顯現。
3. 座標牽引。
4. 融入歸屬界。

秦無漏只能在第二至第三階段之間完成截界。窗口會隨目標修為、契約等級與距離縮短。

界歸契約通常透過祖契釘寫入界胚，讓開界者未來的天地天然歸屬家族。祖契釘可以在開界前拆除或改寫，但會使家族失去培養回收權，因此被各大世家視為重罪。

一方天地若存在結構完整、座標獨立的子界門，截界者可在完全解析子界門後進行選擇性截取。被放棄的區域仍按原契約界歸。選擇性截界需要更精細的法則接觸，操作窗口也更短。

部分祖界使用保城契，把居民生命、壽命與記憶預先列為界歸穩定燃料。掌界人死亡或祖界遭強制回收時，保城契會先犧牲指定居民，降低城市與核心土地散逸。契約可以由掌界人解除，也能在城市居民共同授權下被外力切斷。

## 七、中樞與定額

天衡中樞負責：

1. 維持界域外殼。
2. 鎮壓虛無風暴。
3. 管理界歸與空間分配。

中樞每年向各勢力收取土地、人口、資源或等價界力，統稱定額。世界每年損耗十三份，中樞目前只能補回十份。世界越弱，修補同一處裂口所需成本越高，定額因此逐年增加。

所有大勢力都知道制度正在加速末日。任何一方率先停止吞噬，都會先失去軍力、資源與界域安全。

## 八、上層真相

整個天衡界域位於更高存在的天地內。天衡文明吞噬下層空間的方式，與上層世界準備煉化天衡界域的方式相同。

這項真相只在第五卷完整揭露。前四卷可透過異常天象、遺界記錄、相似界歸結構與殘核缺失記憶留下證據。

## 九、第一卷操作性規則

1. 截界必須接觸目標的血、界力或核心法則。
2. 殘核只能指出弱點，不能替秦無漏完成攻擊。
3. 第一次截界會吞入一座破敗邊鎮及其外圍村落，總人口約三千至五千。
4. 居民不會立即效忠，初期多數人認定秦無漏毀滅了原來的天地。
5. 破城固定後成為第一個心臟錨點。
6. 秦無漏前期借出的界力必須在數息內使用，無法隔夜儲存。
7. 空間內外時間流速暫定一致。
