# 連續性與待決事項

## 已統一設定

### 第一個被吞入的空間

統一為一座破敗邊鎮及外圍村落，人口約三千至五千。第一次落入空胎時，外圍村落先顯現，主城隨後被牽入，因此可同時保留「破敗村莊」與「破城」兩種畫面。

### 空胎與界力

秦無漏初期不能在體內長期儲存個人界力。居民秩序能在已固定土地內形成循環，殘核可建立臨時通道讓他短暫借用。借力結束後必須由具體區域承擔代價。

### 無邊界

空胎沒有完整外殼，不代表其中沒有局部界壁。被吞入的土地透過城市、河流、山脈或界門形成錨點。

### 空間進入方式

第一塊土地固定後，秦無漏可透過臨時界門讓肉身進入。若界門崩潰，他可能被困在內部。早期不能隨念頭瞬間進出。

### 主角對居民態度的演變邏輯

秦無漏對空間居民的態度演變分為三個階段。初期行動中已可出現他未自覺的倫理底線，不得為了強調「冷酷」而否定既有行動：
1. **初期（被迫生存）**：無界核、身受重傷，無法鎮壓四千居民；若居民崩潰，土地與他本人都會毀滅。他先以生存與資產帳理解履約，卻已不願把活人當一次性燃料。
2. **中期（功利計算）**：發現「居民秩序 = 第一顆心臟 = 界力產出」，並把契約視為比一次性煉化更高效的長期方案。但居民的具名死亡、拒絕與主動協作會逐步使他無法只用資產解釋自己。
3. **第一卷高潮與後續（自覺承認）**：他拒絕殘核兵器化全體居民的方案，並且承認「可以撤回卻仍願意維持」才是新秩序的來源。對內借力必須有用途、期限、風險上限與撤回權；緊急狀態也不自動取消這些條件。

## 第十批新增連續性（第111至120章）

1. 剪角制度：萬族牧場割除異族頭角。角是異族感應法則的器官，用於聽土地需求、辨母根牽引與命令真偽；剪角後異族分不清己念與牧律植入，形成終身依附。鋸面平、抹一層根漿封口，人不死、角不再生。被剪者唯一共同記憶是「某一天頭頂的天空不見了」，其餘私人記憶多不完整；這段共同記憶正是痛泉能辨識被剪角者的依據。棘蘿在押送途中被截、未過剪角門，故枝角完整，屬青角族中少數例外。
2. 萬族牧場為各大界主合圈之地，沒有全場共用的單一祖契釘或界歸線；殺死管事不能打開整場界歸門。各分區仍有地界與運貨口，第111章半段座標不足以解析。看守分為三家世家（東、南、西牧區）與補天院（中路與帳）；青崖西南運界道與第9章囚車同路，沒有經過九年。
3. 痛泉「只護不收」只准接續求援者主動送出的訊號，不准深入記憶或代答治療同意。第111章兩名守墓者超收後停止接訊，安排熟人照護，痛泉降載只保留斷續影子與已抄半段座標；事故不能靠再加人持續超收。
4. 第111章為第110章落穩翌晨，人口仍49,212人，糧餘約六日。秦無漏承認藥界失聯兩鎮的分泉傷害與修泉責任；臨時求救可接應，土地、入籍與整籠意願另作決定。
