# 科幻文明與星際擴張

## 定位

《無漏》後期由修行文明逐步轉入界律科學、虛空工業與星海文明。轉型來自前期規則被測量、複現、標準化與工程化，不更換世界觀。

科幻感的核心是「文明能否把原屬於少數強者的神跡，變成可維修、可追責、可量產的公共能力」。

## 舊設定到科技的對應

| 舊設定 | 科學化後 | 文明用途 |
|---|---|---|
| 界核 | 座標反應爐 | 供能、穩定空間、推進世界艦 |
| 殘核 | 界律計算核心 | 模擬法則、航路運算、艦隊協同 |
| 界骨 | 高階座標材料 | 艦體龍骨、人工錨、星門 |
| 殘序 | 可編輯法則片段 | 武器、醫療、環境模組 |
| 互助契 | 分散授權協定 | 母港治理、聯合供能、艱難時的撤回權 |
| 虛舟 | 前期界際航行器 | 發展成工程艦、探測艦與世界艦 |
| 無歸座標 | 非世族公共錨 | 獨立航行、死後資訊主權、母港核心 |

## 世界艦標準結構

1. 艦核：人工界核、能源與主座標。
2. 錨骨：承受界間應力的界骨龍骨。
3. 生態環：城市、農業、水循環與異常生命區。
4. 界工廠：處理殘序、修復模組、生產錨材。
5. 法則甲帶：以可更換模組對應不同宇宙環境。
6. 公民授權網：艦員對高風險功能的分層授權與撤回機制。
7. 子核群：與殘核共生的多智能體，各有權限、記憶與反對權。
8. 無歸庫：保存個體遺言、死後資訊與非世族歸處。

## AI 艦靈

AI 艦靈不是全知天道，而是由殘核子核、界律模型與艦內授權共同組成的多智能體。每一艦靈必須登記本體、權限、記憶來源、模型盲區、反對權、停機條件與可遷移範圍。

| ID | 艦靈類型 | 核心任務 | 不可越權事項 |
|---|---|---|---|
| AI-N01 | 導航艦靈 | 比較錨時、艦時、母港時並預測航路應力 | 不得自行改變目的地或隱瞞可返航路線 |
| AI-E01 | 生態艦靈 | 維持糧源、水循環、人口承載與污染隔離 | 不得以最佳化名義取消居民生育、醫療或撤離權 |
| AI-D01 | 債務艦靈 | 登記界債、傷亡、授權與跨代求償 | 不得刪除失敗紀錄或替指揮者免責 |
| AI-W01 | 戰術艦靈 | 協調感測、火力、甲帶與撤退窗口 | 不得在公民授權層級不足時擴大任務目標 |

艦靈可以分殖、沉睡、拒令、被污染或選擇效忠子艦。它們的效率越高，越需要保留可追溯決策、少數意見與人類可執行的降級模式。

## 艦種

| 艦種 | 任務 | 戲劇性限制 |
|---|---|---|
| 探錨艦 | 尋找航路與可定居錨點 | 探測本身會暴露位置 |
| 工程艦 | 建星門、修錨點、回收殘界 | 載重高、速度慢、需艦隊保護 |
| 糧源艦 | 生態、食物與活體資源 | 為艦隊最脆弱也最重要的目標 |
| 界戰艦 | 壓制敵方錨點與艦體 | 每次主砲都會消耗自身法則完整度 |
| 牽引艦 | 移動殘界、天體與世界核 | 牽引期間幾乎無法轉向 |
| 文明母艦 | 長期移動城市與治理中心 | 內部分裂會破壞主錨與生態系統 |

## 航行、能源與後勤

1. 艦隊只能沿已觀測的座標梯度航行，不可無限跳躍。
2. 反應爐提取座標位差時，會向航路排放熵債。需要清債艦或可承載殘序的無主區。
3. 跨界後統一計時可能失效。每支艦隊同時維持艦時、錨時與母港參考時。
4. 糧食、可呼吸介質、錨材、法則完整度、活體人口與信任授權都是後勤資源。
5. 人口不能只以數字補充。專業知識、文化差異與生育週期會限制擴張。

## 星門運作規則

1. 星門不是任意傳送術，而是兩個人工錨之間持續維持的座標走廊。
2. 開門前必須校準兩端物質常數、時間基準、污染等級與可承受流量。
3. 任一端撤回授權、失去供能或座標漂移，通道都必須進入限流、疏散或關閉程序。
4. 星門可被封鎖、徵稅、誤導與軍事化，因此每座星門同時是基礎設施與主權爭議。
5. 斷門期間仍在走廊內的艦船不會免費抵達，可能被迫進入虛無航行並形成救援債務。

## 掠界行動標準流程

1. 探錨：識別目標的生命、主權、污染與錨定狀態。
2. 分類：無主殘界、可交涉文明、敵對文明、捕食性世界、不可接觸區。
3. 授權：依目標類型取得艦內對應層級的公民授權。
4. 壓制：切斷敵方外部錨點，保留平民生態與可撤回通道。
5. 接錨：建立臨時錨點，對齊時間、因果與物質常數。
6. 回收：取得材料、設備、殘序或航法資料，並完成污染隔離。
7. 審計：登記傷亡、被迫遷徙、界債、獲益去向與求償權。
8. 撤離或共治：禁止把暫時軍事控制自動轉成永久所有權。

## 文明債務台帳

每次大型工程、航行或掠界都要同時登記五類文明債務：

1. 物質債：被消耗且不可立即補回的錨材、糧源、法則完整度與生態容量。
2. 人命債：傷亡、折壽、失蹤、被迫遷徙與尚未完成的救援義務。
3. 主權債：未經完整同意的徵用、占領、封鎖與代表權缺口。
4. 記憶債：被刪除、壓縮、污染或壟斷的個體與文明記錄。
5. 跨代債：由後代、子艦、母港或異文明承擔而未參與原始決策的成本。

債務台帳必須列出責任者、受害者、受益者、可追索期限、修復方案與仍無法償還的部分。勝利不會自動沖銷債務。

## 掠奪的故事原則

「掠界」是艦隊時代的常用語，可包含遺跡回收、拯救、強制徵用、爭奪資源與殖民。每次行動必須標明目標是否有主、資源是否可再生、居民能否拒絕、艦隊承擔什麼後果。

秦無漏的艦隊可能從維生型回收走向常態化掠奪。重要後期衝突是他們是否正變成新的天衡主界。

## 艦隊內部主要路線

| 路線 | 目標 | 風險 |
|---|---|---|
| 母港派 | 優先建設、安置新居民 | 擴張太慢，可能被強敵消耗 |
| 遠征派 | 用艦隊建立戰略縱深 | 遠方艦隊逐漸形成獨立政體 |
| 掠界派 | 先奪取能源與科技才能存活 | 把維生的例外變成統治常態 |
| 共生派 | 與異文明共建錨點和星門 | 共同體內部常數可能不相容 |
| 核心派 | 讓殘核子核群接管高風險決策 | 效率超越人類後，授權難以收回 |

## 異文明設計模板

每個重要異文明至少定義：

1. 宇宙常數與生存介質。
2. 個體、群體與記憶的邊界。
3. 能源、繁殖、死亡與繼承方式。
4. 技術樹上的強項與不可解決弱點。
5. 對主權、承諾、交易與戰爭的定義。
6. 與無漏文明互補的需求。
7. 一個不可透過戰鬥解決的核心爭議。

## 長期故事引擎

1. 新錨點會帶來新環境、新科技、新主權問題。
2. 子艦離港後會發展自己的法律、語言與人工天道。
3. 每次大型掠界都會同時解決一個生存危機，製造一筆文明債。
4. 殘核子核會分殖、沉睡、竄改記憶或選擇效忠新艦。
5. 母港與遠征艦隊的通訊延遲會產生實質政治分裂。
6. 上層世界可能將整個宇宙視為可移動、飼養或收割的艦隊資產。

## 前期埋線順序

1. 第51至60章：第一組可比較界律參數。
2. 第61至80章：不同城的參數可校準，出現工具原型。

4. 第141至200章：首座公共錨與原型母港成形，天衡舊秩序裂解。
5. 第201章後：界律量尺、人工錨與界律計算機進入工業化。

## 禁止事項

1. 不突然出現與界律無關的地球科技樹。
2. 不使用無代價、無距離、無錨點的任意瞬移。
3. 不讓艦隊只靠秦無漏個人境界運作。
4. 不將異文明簡化為單一怪物種族或免費資源包。
5. 不把掠奪的人口、生態與政治後果省略。
6. 不讓人工智能擁有無條件全知，它們受權限、記憶、模型與本體安全限制。
