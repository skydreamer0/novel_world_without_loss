# 角色與勢力

## 秦無漏

### 公開身份

秦氏嫡系天才，原定成為家族下一代核心。開界大典失敗後被診斷為空胎，遭除名、退婚並收回父親遺產。

### 真實起點

極品界種遭秦懷忠奪取。界胚被撐開後沒有形成界核，殘留一個無法測量的空胎。

### 外在性格

1. 克制，擅長觀察制度漏洞。
2. 不輕易向人求助。
3. 習慣先計算風險，再表露情緒。
4. 被羞辱時很少當場反擊，會記住具體人名、利益與證據。
5. 冷酷主導，極致實用主義。對界內生靈維持絕對威懾與掌控，不接受任何形式的議會脅迫或制度綁架。

### 內在矛盾

他痛恨家族把人當作資源，自己在求生時也會把天地、傳承與居民視為可用之物。每次吞界都逼他面對同一個問題：他與奪走界種的人究竟有多大差別。

### 五卷弧線

| 卷 | 狀態 | 關鍵選擇 |
|---|---|---|
| 空胎 | 只求活下去與追查真相 | 截走殺手天地，承擔陌生居民 |
| 獵界 | 主動獵殺腐敗界主 | 放過秦昭，不取回界種 |
| 損耗 | 相信自己能替所有人決定 | 向未來借力，造成萬界城衰敗 |
| 逆流 | 接受自治與多中心治理 | 分出界圖權限 |
| 開天 | 有能力成為新中樞 | 交出永久控制權 |

## 殘核

上一紀元文明中樞的殘留核心。

### 說話規則

1. 話少。
2. 不主動說謊。
3. 只回答被問到的部分。
4. 遇到倫理問題時先給出數字與存活率。
5. 不使用安慰性語言。
6. 記憶不足時只說「資料缺失」。

### 隱藏目的

殘核曾推動唯一大界計畫。它認為上一輪失敗源於執行不完全，並暗中把秦無漏視為更合適的核心。當秦無漏開始冷酷地使用半生軀、離影剝奪與壽元租賃時，殘核內部評估為「絕對理性復甦」，會暗中讚賞並悄悄解鎖更多上一紀元的禁忌權限，試圖引導秦無漏成為極致的合界兵器。

### 關係弧線

1. 前期是秦無漏唯一可靠的工具。
2. 中期成為知識導師與策略顧問，暗中誘導秦無漏邁向極致冷酷高效。
3. 後期顯露價值觀衝突，秦無漏察覺殘核的心理誘導並拒絕成為其兵器。
4. 終局試圖奪取界圖權限，迫使秦無漏在效率與自由之間選擇。

## 秦昭

得到秦無漏極品界種的天才。

### 核心設定

1. 品行端正，真心保護秦氏與青崖城。
2. 前期不知道界種來源。
3. 享受制度利益，也承擔制度要求的定額與責任。
4. 體制異化悲劇：為保住核心三城平民，被迫默許家族抽乾外圍村落骨血，在良知與殘酷現實之間日漸心理撕裂與硬化。
5. 得知真相後不會立刻倒向秦無漏。

### 對照功能

秦昭證明良善的人也可能維護有害制度。他與秦無漏都想救人，差別在於秦昭試圖在腐敗體制內苦苦支撐並承受悲劇異化，秦無漏則以冷酷手段打破舊秩序並承受崩塌風險。


### 關係節點

1. 第一卷第17至18章：秦無漏確認界種在秦昭身上，放棄強行取回。
2. 第一卷第25章：秦昭完成百里開界，看見秦無漏留下的空胎記憶。
3. 第一卷第37至40章：秦昭取得轉種證據，與秦無漏初戰後共同阻止提前界歸。
4. 第一卷第46章起：確認界種來源，拒絕拔出已承載三百一十二人的界種，停止初界擴張並公開追究秦懷忠。
5. 第二卷末：兩人完成關鍵決戰，秦無漏再次選擇不奪界種。
6. 第三卷：秦昭替中樞作戰，也暗中保護平民。
7. 第四卷：帶領秦氏殘部加入無漏之地。
8. 第五卷：守住多族議會制定新界律的時間。

## 秦懷忠

第一卷主要敵人，開界儀式的直接執行者。

### 動機

他奉家族密令把極品界種轉移給更符合整體利益的人。他相信一名天才的犧牲可以換取秦氏延續，因此沒有把自己視為惡人。

他也是忠脈祖界現任掌界人，控制十二座城市與十二萬六千餘名居民。忠脈長期無法完成家族和中樞定額，他以犧牲遠村、帳外人口和空胎者維持主城。居民的生存使他每項罪行都具有可被辯護的現實收益。

### 第一卷功能

1. 具體承載秦無漏的復仇目標。
2. 逐步揭露家族制度與界歸利益。
3. 逼迫秦無漏連續截界，讓空間急速成長並產生疾病。
4. 死亡後留下通往秦昭與家族決策層的記憶。

## 天衡首座

天衡中樞最高掌權者。

### 核心信念

他確知世界即將死亡，也計算過所有溫和方案的失敗率。他願意犧牲九成人口，集中所有空間，換取唯一大界延續萬年。

### 使用原則

1. 不寫成單純暴君。
2. 每次殘酷選擇都要有可驗證的災難數據。
3. 他會真正救下部分人，並讓秦無漏的方法承受現實檢驗。
4. 他與殘核的相似逐卷增加。

## 第一卷外界角色

### 蘇晚照

秦無漏原未婚妻。她接受蘇家解除婚約的決定，親自前往醫館處理婚書，沒有羞辱秦無漏。她留下不受蘇家控制的照影玉，使秦無漏得以保存被刪除的儀式波形。

### 秦玄度

秦氏醫官。判定秦無漏終生空胎，也承認「無法測量」不等於容積為零。他沒有公開違抗家族，只以延後回收器具的方式留下查證機會。

### 秦元朔

秦昭叔父，負責秦昭開界前的所有事務。他阻止秦昭介入秦無漏事件，將開界提前至十五日後。

### 秦罡

秦懷忠旁支界修。名下沉河城三十六里，原有人口四千三百二十九。因定額逾期、界核三裂而接受滅口任務。死亡後天地遭秦無漏第一次截界。

### 秦徹

秦無漏之父，生前曾負責秦氏界種帳冊。他發現家族按回收價值預分界種，也知道空胎候選者會被送往黑礦與虛無作為消耗品。他私下拆除秦無漏體內的祖契釘，使秦氏無法在秦無漏死後回收其天地。此舉促使家族把無相界種改配給秦昭。秦徹已死，死因與帳冊被封存的經過仍待追查。

### 賀鳴川

青崖城巡界司校尉，負責追查秦罡界歸中斷案。作風冷靜，會優先保住證據與部下，不會為秦氏私怨犧牲整支隊伍。發現乙七庫與巡界司押送帳後，選擇保存證據並把三十二名囚犯送往可公開查驗的慈幼院，尚未與秦無漏結盟。

### 灰七

巡界司第七號追界犬。梁禾發現牠體內埋有控制鏈，秦無漏替牠切斷命令端後收入空胎。灰七仍保留通往犬庫的界歸線，既能追蹤外界殘留座標，也可能成為巡界司反向定位的入口。

### 陸停雲

四十七名空胎者中唯一確認存活者，長期被囚於下池黑礦，作為穩定爆界陣的人形空錨。獲救後拒絕立刻加入虛舟盟，要求先由新名冊承認身份。他與黑礦骨腔形成無核錨點，堅持秦無漏不得擅自借用空胎者承受反噬。

### 袁細、季小山與余鹿

下池黑礦獲救者，經檢查確認均為開界紀錄遭抹除的空胎。三人與陸停雲共同拆除黑礦追印。余鹿遭殘序黑紋侵蝕，暫時拒絕使用會洗去自身記憶的虛無洗名水。

### 紙鳶

虛舟盟接引使，使用沒有固定來處的殘缺界門。她曾進入上一紀元遺界並失去部分影子，持有秦徹最後一次虛無航行紀錄。她以沉肺草交換遺界門片解析，對空胎者曾被虛舟盟當作活錨一事承認責任。

### 石苦

下池黑礦老礦工，熟悉礦道、生命錨與柴岳的處刑規則。救援時主動協助切斷礦奴契，暫時成為二百八十三名獲救礦工的代表。

### 柴岳

下池黑礦主人，以礦奴生命維持界壁和爆界陣。第二十章死於礦場突襲，其內界仍按原契約界歸，十二里黑礦與礦奴區遭秦無漏選擇性截取。

### 顧寒生

秦徹最後一艘虛舟的副手，右腿在第九裂帶航行中失去。秦徹死後，他帶六百一十三名帳外居民藏在忠脈灰脊夾層，保存承界甲令照影與無歸座標線索。

### 孟直

三槐村村長。面對抽村界令時，要求秦無漏公開空胎的糧食與生存風險，再由全村投票。遷入空胎後帶領八百二十三名居民建立三槐台。

### 桑遲

忠脈柳峽城老水官，代表柳峽參與第一次忠脈議場。他支持城市居民自行承擔選擇後果，主持解除保城契表決與自治初期治理。

### 羅盡城

忠脈石門城守將。起初接受攻打柳峽的軍令，最終帶領三千守卒拒戰，以自身血契換取石門解除保城契。第四十八章死於城門崩塌，遺命取消羅氏世襲將位。

### 盧四海

石門城議代表。主持二千一百零四戶解除保城契表決，並在羅盡城死後代表石門與柳峽簽署互助契。

### 遲影

紙鳶十二歲時以斬影術留在第九裂帶的影子，獨自在遺界入口存續十七年。第四十五章拒絕回歸紙鳶，自取姓名並以獨立異常生命登記。它保存秦徹無歸座標的部分見聞，也能承載照影殘序。

### 晏平章

天衡中樞補天使者，持補天短尺與三枚補天印。言語平靜，從不迴避傷亡數字，能以中樞資源迅速修補地方界壁。他承認乙七庫違法，仍依緊急條款支持集中治理，要求封存甲字令、遺界門片與殘核。

## 秦氏

青崖城第一世家。表面維持公平開界制度，實際透過資源評分、血脈排序與隱密轉種，把優質界種集中給少數核心。

秦氏的制度邏輯：

1. 個人的界種屬於家族長期投資。
2. 死亡後天地會界歸，培養成本不會完全消失。
3. 空胎沒有回收價值，因此可被迅速除名。

## 天衡中樞

三派並存：

1. 守舊派：維持定額、界歸與既有分配。
2. 合界派：推動唯一大界。
3. 補天派：尋找降低損耗或回收虛無的方法。

三派都可能與秦無漏合作，也都可能傷害無漏之地。

## 萬族牧場

各大界主共同控制的異族繁殖區。異族按法則相性、成長速度與煉化產出分類。部分族群已失去原生歷史，不知道真正天空的模樣。

## 虛舟盟

進入虛無探索遺界的組織。成員多為空胎、罪犯、異族與失去家族的人。內部兼具冒險者、拾荒者、走私者與遺界學者。

## 無漏之地

核心權力結構與制度：

1. **依附鐵律**：界內生靈與土地在空間、生存層面完全依附於秦無漏（空胎宿主），秦無漏為唯一全域錨點。
2. **議會定位**：民事行政管家與後勤協調機構，處理配糧、修繕與內部糾紛，無權否決或限制界主的戰術、調用界力與對外決策。
3. **禁止煉化活人**：界主不強制抹煞活人生靈，但生靈必須履行維系空間心臟穩定的義務。
4. **禁止強制開界**：維護無漏之地法則獨立性。
5. **空胎者處置**：空胎者可獲得土地與身份，但需納入生靈名冊。
6. **各族與城市自治**：城市與各族在民事上享有自治權，軍事、界力與生死處置權歸界主所有。
7. **土地與界力分配**：依貢獻與界主戰略需求分配。
