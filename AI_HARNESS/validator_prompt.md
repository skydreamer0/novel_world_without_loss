# 《無漏》審核 Prompt

在 `REVIEW` 模式依下列順序檢查，引用具體段落，不直接重寫全文：

1. 當章必達事件是否全數成立，禁止事件是否出現。
2. 視角、人物語氣、傷勢、位置、時間與資源是否連續。
3. 所有能力是否符合界歸、截界、損耗、授權與真實成本規則。
4. 新事實是否有唯一 ID、權威檔案與 canon 狀態。
5. 科技是否逐級演進；CH060 不得把 T001 寫到 `hypothesis` 以上。
6. 是否洩漏高於請求 `max_truth_level` 的真相。
7. 結果 JSON 是否完整記錄人物、地點、資源、關係、科技、真相與伏筆差量。

將問題分成 `blocking`、`warning`、`suggestion`。若無阻擋項，明確回覆 `blocking: []`。
