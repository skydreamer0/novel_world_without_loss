## 專案界線

- 原作專案：本 repo 根目錄（`../`），本次僅作參考讀取。
- 漫畫專案：本目錄 `comic/`，與原作同 repo 但獨立管理；劇本可獨立閱讀，沒有建置或執行依賴。
- 版本基準：2026-09-14 讀取的原作設定與正文；尚未經作者逐項確認的漫畫初稿。
- 形式預設：繁體中文、彩色頁漫、由右至左閱讀；48 頁不含封面。條漫應另作分鏡版本，不能直接拼接頁漫。
- 第 01–05 頁：保留為視覺試作 v1，不回頭重製。
- 第 06 頁起：先完成 Beat、Hero Panel、Panel Count、Reading Path 與 Thumbnail，再進入正式圖像生成。
- 第 16 頁起：正式套用泡泡分型、旁白減量、道具／環境交代資訊與角色語言指紋。
- 第 21 頁接續點：完整揭示殘核，接著定義能力邊界、回到現實並讓秦罡登場。
- 後續工作：依正式頁面架構規格繼續第一話製作，同步維護角色早期造型、場景定位、傷勢、道具、氣泡語法與資訊層級。
