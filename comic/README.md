# 《無漏》漫畫獨立改編專案

本專案以小說《無漏》為原作，獨立管理漫畫的敘事、話數、劇本及後續分鏡。漫畫話數不對應小說章數；本專案的新增橋段與調整不回寫小說設定。

目前交付：第一話編劇初稿 v1.0，48 頁、168 格加長開篇。已完成逐頁逐格腳本，尚未製作漫畫圖稿。

- [第一話〈你死後，天地歸誰？〉完整劇本](episodes/001_你死後天地歸誰_劇本.md)
- [漫畫企劃與敘事原則](development/01_漫畫企劃.md)
- [第一話改編、連續性與製作備註](development/02_第一話製作備註.md)

建議先讀完整劇本，再看編劇備註。劇本內「畫面」「節奏」「美術」屬製作指示；只有明列的對白、心聲、字卡、音效進入成品。

## 專案界線

- 原作專案：本 repo 根目錄（`../`），本次僅作參考讀取。
- 漫畫專案：本目錄 `comic/`，與原作同 repo 但獨立管理；劇本可獨立閱讀，沒有建置或執行依賴。
- 版本基準：2026-09-14 讀取的原作設定與正文；尚未經作者逐項確認的漫畫初稿。
- 形式預設：繁體中文、黑白頁漫、由右至左閱讀；48 頁不含封面。條漫應另作分鏡版本，不能直接拼接頁漫。
- 後續工作：以本稿進行縮圖分鏡、角色早期造型適配、場景定位，再進入正式繪製。
