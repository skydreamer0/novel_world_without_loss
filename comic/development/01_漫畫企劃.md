# 《無漏》漫畫企劃 v1.0

## 作品承諾

被家族奪走開界機會的少年，靠截取死者的天地活下去。但每次得到力量，都有一群活人必須承受他的決定。

讀者首先追秦無漏如何脫困，接著追他如何養活自己的世界，最後追他能否容許世界裡的人拒絕自己。復仇提供前進的力量；每次勝利究竟把誰變成代價，構成這部作品持續變化的衝突。

## 第一話的完整戲劇單位

**話名：〈你死後，天地歸誰？〉**

秦無漏想完成開界，取得自己能作主的天地。儀式中的蓄意奪種，讓他失去這個未來；家族隨即依據剩餘價值收回供養與父親的住所。被送往廢院後，他察覺滅口安排，以父親遺物中的殘核協助分析，借殺手自己的力量反擊。殺手將死，他第一次有機會從家族手裡奪回一方天地，於是冒險截界。天地確實進入他體內，四千多名居民卻開始隨土地一起崩落。

本話完成「被奪走一切的人，主動奪走一方天地」；下一話必須回答「他憑什麼接管這些人的命」。

## 開場的情感支點

先用孩子的一句「那我呢？」建立父親、家族與繼承的矛盾。秦無漏最初相信父親留下的世界也會保護自己。稍後家族收走院落，讀者便能自行認出這份承諾在哪裡落空。

第一話不安排群眾輪流辱罵。最傷人的事情是醫侍仍替他包紮，卻必須收回他下一帖藥的資格；議堂仍稱他秦氏子弟，卻不讓他住在父親留下的院子。

## 主角表演

秦無漏十七歲，受過十一年訓練，懂辨識法則與估算資源，身體仍會顫抖、失血、被打倒。他習慣先計算，再把害怕壓下去。讀者應看得到壓下去的過程。

本話給他三次主動決定：發現異常後要求查紀錄；發現廢院陷阱後留下假象；明知沒有界核仍冒險截界。第一次被制度擋下，第二次讓他活下來，第三次使他必須承擔新的災難。

他在戰鬥中關心居民，但也需要那方天地求生與翻身。鏡頭明示由他刺入裂縫的鎮壁釘加劇了城內崩塌。不能把最後的截界寫成毫無私心、毫無責任的救世行為。

## 第一話的角色配置

| 角色 | 戲劇作用 | 表演限制 |
|---|---|---|
| 秦無漏 | 被計價的人，逐漸成為決定他人命運的人 | 不以口號代替判斷；無法術碾壓 |
| 秦昭 | 仍想幫他的家族成員，也是奪種疑雲指向的人 | 真心援助；本話不證實知情受益 |
| 秦懷忠 | 掌握儀式與善後的權力者 | 不獨白解釋陰謀；動作永遠合乎身分 |
| 秦玄度 | 能看見制度漏洞、只能給少量幫助的醫官 | 不送解方；「測不到」與「零」要分開 |
| 秦罡 | 用別人的土地與性命延長自己生路的殺手 | 有壓力、有手段；不因窮困免除責任 |
| 殘核 | 提供精確但狹窄答案的異常器物 | 不攻擊、不讀心、不授予界力 |
| 沉河城居民 | 把勝負從兩人的戰鬥擴大為公共災難 | 先給一戶人的行動，再給人口總數 |

蘇晚照、秦元朔暫不具名出場。父親只出現幼時記憶；族老、醫侍、居民不另加名條。

## 節奏與篇幅

| 頁數 | 讀者此刻在追什麼 | 段落結果 |
|---|---|---|
| 01–09 | 他會得到怎樣的世界？ | 界種從眼前被移走 |
| 10–17 | 家族會替他查明真相嗎？ | 調查拖延，人先被除名 |
| 18–24 | 廢院與父親遺物藏著什麼？ | 他有分析手段，殺手已抵門 |
| 25–35 | 沒有力量的人如何傷到界修？ | 借力震甲，接血看見城民 |
| 36–41 | 為了活下去，他會做到哪一步？ | 他主動終結秦罡生命 |
| 42–45 | 他能否截走原應歸族的天地？ | 奪取成功 |
| 46–48 | 成功之後，代價落在誰身上？ | 城在空胎中崩毀，一百息倒數 |

開界大景、第一次看清城民、截界大景各負責不同資訊。大景不能全用相同的仰角少年加法陣構圖。

## 漫畫的視覺語法

1. **門與手。** 父親的手、收回藥牌的手、抓碎片的手、按上界門的血手；由被保護轉為取得控制權。
2. **有界與無界。** 秦氏景觀用完整環形、平直格框；空胎用看不到盡頭的黑場。空胎初次出現絕不能畫出球形外殼。
3. **力量與人。** 秦罡每次加大術力，插入同一戶城民的處境變化。鏡頭對接構成因果，不靠講義解說。
4. **聲音。** 開界十七鐘齊鳴、事故停鐘、廢院封聲、截界後居民鐘聲。靜默必須有畫面可讀。
5. **尺度。** 開場山下的人很小；末尾主角體內的城很小，但城中人物的近景與主角等大，維持其生命的分量。

## 首話資訊上限

讀者只需掌握：人體能容納天地；開界只有一次；沒有界核就難以固定土地及使用界力；界主死後天地歸家族；殘核能分析弱點；秦無漏能在死亡交接的短暫窗口截界。

無相界種不講屬性分類；定額只解釋成欠繳的土地資源；上層世界、文明合成、天衡赤字、殘核身世均延後。煉化通常損失三成的規律留待第二話以實際清點呈現，本話不宣布「已經無損」。

## 下一話接口

第二話暫名〈誰准你救我們？〉。秦無漏帶傷進入沉河城，被守卒當成毀城者；沈季年要求他先協助固定城池。主角需要居民認路、敲鐘、引水與界定邊界，才能形成局部錨點。城穩住後，居民有權追問他殺人、奪界與處置他們的理由。

這裡只鎖定承接，不預寫第二話完整劇本。
