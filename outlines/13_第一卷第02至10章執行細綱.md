# 第一卷第2至10章執行細綱

## 章群主題

秦無漏在九章內失去原有身份、第一次殺人、第一次截走他人天地，也第一次發現被他吞入的空間裡住著真實的人。

章群核心問題：

擁有一方天地，是否自然擁有其中的一切？

| 秦昭 | 秦氏另一名天才 | 關心秦無漏，不知真相 | 被家族隔離，準備提前開界 |

## 第二章：空胎

### 本章作用

1. 把第一章的公開墜落轉成制度性剝奪。
2. 證明測不到邊界被所有人解讀為容積為零。
3. 讓秦無漏取得被刪除的界力波形。
4. 完成解除婚約。

### 場景

1. 醫館複測：九環界尺、探界針與活界砂全部失效。活界砂進入空胎後消失，沒有回音。
2. 待遇中止：醫館藥物、護衛與嫡系通行權在結果確認後立即凍結。
3. 秦昭探視：秦昭想調查儀式，被長輩秦元朔帶走，透露他將提前開界。
4. 蘇晚照退婚：她不羞辱秦無漏，直接說明婚契也連接界歸與兩家資產。婚約解除後，她留下自己的照影玉。
5. 查閱紀錄：秦無漏發現儀式原始波形缺少三息，從醫官的備份界尺中取回一小段殘像。

### 情緒轉折

秦無漏從等待家族查明真相，轉為確認家族正在主動刪除痕跡。

### 章末

殘像中的極冷界力，與秦懷忠按在他背心的力量完全一致。

## 第三章：除名

### 本章作用

1. 展示秦氏如何用合法程序完成切割。
2. 收回父親資產。
3. 讓秦懷忠有合理理由安排滅口。
4. 交付殘核載體。

### 場景

1. 族議聽證：秦無漏提交殘像，秦懷忠以波形殘缺與儀器污染否認。
2. 回報率計算：族老說明空胎無法界歸，秦無漏繼續享受嫡系資源將使家族永久虧損。
3. 秦昭出面：他願意以自己未來定額擔保秦無漏三年，遭秦元朔以開界前不得負債駁回。
4. 資產收回：父親院落、界砂配額與護衛被收走。秦無漏只能從待銷毀遺物中帶走一枚裂紋銅核。
5. 搬離祖宅：秦懷忠安排他前往城西廢院，公開理由是避免空胎污染祖界。
6. 暗中命令：秦罡接下滅口任務，以免秦無漏把殘像交給中樞巡界司。

### 情緒轉折

秦無漏放棄在秦氏制度內證明自己清白。

### 章末

他走入廢院時，看見門縫裡有一層剛落下的灰，院內早有人來過。

## 第四章：殘核

### 本章作用

1. 殘核甦醒。
2. 固定殘核的對話與資訊限制。
3. 展示空胎真實樣貌。
4. 預告殺手。

### 場景

1. 秦無漏檢查廢院，確認有人改動禁制，卻暫未進入。
2. 裂紋銅核接觸空胎入口，被直接吸入黑暗。
3. 秦無漏的意識第一次看見空胎，沒有上下、邊界與回音。
4. 殘核啟動，只回答秦無漏提出的問題。
5. 殘核判定：界核缺失、全域邊界不存在、容積無法測量、正常再開界成功率低於萬分之一。
6. 一段「散逸三成一，未回收」的殘缺記錄閃過，秦無漏無法理解。
7. 外界禁制被切開，殘核透過秦無漏感官判定來者為開界者。

### 情緒轉折

秦無漏得知自己幾乎無法復原，也第一次知道空胎並非單純的零。

### 章末

殘核說：「一名開界者。殺意已成。」

## 第五章：解析

### 本章作用

1. 讓無界的秦無漏面對真正開界者。
2. 解鎖解析。
3. 建立秦罡天地的腐敗與居民存在。
4. 取得血液媒介。

### 場景

1. 秦罡封鎖廢院，自稱奉命護送秦無漏離城。
2. 秦無漏拖延詢問，殘核經他的感官逐步解析對手。
3. 秦罡施展石甲界術，身後短暫浮現沉河城投影。
4. 解析顯示：天地三十六里、人口四千三百餘、界核三裂、定額逾期、北側法則空洞。
5. 秦無漏利用父親留下的舊禁制迫使秦罡全力出手。
6. 界術與禁制相撞，秦罡手臂受傷，血液落入秦無漏掌中。
7. 血液使解析深入，界壁弱點與界歸通道第一次顯形。

### 情緒轉折

秦無漏看見秦罡力量背後有一座真實城池，也看見那座城正在替主人承受透支。

### 章末

殘核說明截界三條件，秦無漏回答：「告訴我最薄的地方。」

## 第六章：截界

### 本章作用

1. 完成第一次越級反殺。
2. 完整演示截界流程。
3. 讓秦無漏在不知情下承擔四千餘人。
4. 建立界歸窗口。

### 場景

1. 秦罡發現秦無漏能看穿界壁，改為立即殺人。
2. 秦無漏用血液標記、殘核解析與父親禁制攻擊北側法則空洞。
3. 秦罡界術反噬，石甲從內部裂開。
4. 秦無漏親手完成致命一擊。
5. 秦罡死後，秦氏祖界牽引線降臨，界門開始顯形。
6. 秦無漏用空胎入口取代回歸座標，在九息內攻破界門。
7. 沉河城及外圍村落被拉入空胎，轉移規模超出預計。
8. 土地邊緣開始失去座標。

### 情緒轉折

復仇與求生的勝利只維持一瞬，隨即變成數千人的生死倒數。

### 章末

殘核回報：「座標崩解，剩餘一百息。」

## 第七章：天地之內

### 本章作用

1. 讓秦無漏肉身首次進入空胎。
2. 建立沉河城居民群像。
3. 固定第一個局部座標。
4. 讓居民保留敵意。

### 場景

1. 秦無漏穿過不穩定界門進入沉河城，天空外圍是一圈正在逼近的黑暗。
2. 城民剛得知秦罡死亡，將新出現的秦無漏視為奪界者。
3. 方折率守卒攻擊，秦無漏沒有足夠界力反制。
4. 阮青禾先要求停止鬥爭，因城西醫坊與數十名傷者正在崩解。
5. 沈季年提出交換：秦無漏先保住城，城民暫停殺他。
6. 殘核找出三個錨點：城鐘、主井、北門。
7. 秦無漏與居民分頭恢復鐘聲、水脈與城門秩序。
8. 城池暫時固定，枯河卻開始倒流進黑暗。

### 情緒轉折

秦無漏第一次必須依靠敵視他的居民才能保住自己的天地。

### 章末

倒流的河水正把城下最後一段地脈拖向黑暗。

## 第八章：第一顆心臟

### 本章作用

1. 展示秩序生成界力。
2. 讓城市完成初步器官化。
3. 完成首次界力借債。
4. 呈現借力由居民承擔。

### 場景

1. 糧倉因座標錯位起火，城民爭搶存糧。
2. 秦無漏無法用力量鎮壓，只能與沈季年恢復名冊、配糧與救火隊。
3. 阮青禾重開醫坊，方折重整守卒，梁禾帶農戶疏通支渠。
4. 人流、物資與命令形成循環，界圖第一次展開。
5. 沉河城出現心臟輪廓，產生微弱界力。
6. 秦無漏向城市借用三息界力，將倒流枯河釘回河床。
7. 借力結束，全城居民同時疲憊，兩名重傷者因此死去。
8. 界圖顯示外界有一列被標記為待煉化的生命座標。

### 情緒轉折

秦無漏救下城市，也確認自己每次使用力量都會從居民身上取走某些東西。

### 章末

外界生命座標正沿秦氏牧場道路移動，預計兩個時辰後消失。

## 第九章：萬族囚車

### 本章作用

1. 引入萬族牧場。
2. 讓秦無漏第一次主動干涉他人煉化。
3. 引入青角族與森林法則。
4. 使空間內部形成兩個敵對群體。

### 場景

1. 秦無漏離開空胎，追到牧場外圍道路。
2. 囚車內關押一百二十七名青角族，預定作為木行空間資源煉化。
3. 棘蘿拒絕向秦無漏求救，警告族人不要相信任何界主。
4. 押送開界者啟動藤牢界術，秦無漏透過解析看見其法則依賴囚車內的母根種。
5. 秦無漏借沉河城三息界力，切斷藤牢與母根種的從屬關係。
6. 青角族反奪囚車，殺死押送者。秦無漏沒有截取對方天地，避免再次引入失控人口。
7. 棘蘿同意進入空胎，條件是保留武器、母根種與自治。
8. 沉河城拒絕開門，雙方隔著城牆對峙。
9. 母根種在黑暗土地發芽，根系自行刺向城市心臟。

### 情緒轉折

秦無漏第一次允許一個不服從自己的群體進入天地。

### 章末

界圖同時將城市與森林標記為「核心」，兩者開始爭奪同一條地脈。

## 第十章：記憶雨

### 本章作用

1. 爆發第一場法則衝突。
2. 讓世界異常同時製造災難與揭密。
3. 促成沉河城與青角族的第一次合作。
4. 發布截界者通緝令。

### 場景

1. 森林根系穿入城牆，屋木發芽，井水出現木腥味。
2. 沉河城要求焚毀母根種，棘蘿表示母根死亡將使青角族法則崩潰。
3. 秦無漏試圖劃分邊界，空胎沒有足以裁決兩種法則的上位規則。
4. 初次截界、秦罡殘念、押送者死亡與母根種共同攪動殘序。
5. 天空降下記憶雨，所有淋雨者看見陌生人的記憶。
6. 人族看見青角族被圈養與煉化，青角族看見沉河城居民長年替秦罡承擔定額。
7. 秦無漏看見秦懷忠在祭壇下轉動一道座標，畫面在目的地顯現前中斷。
8. 沈季年與棘蘿共同重排城渠與根系，讓城市和森林各自取得循環。
9. 外界巡界司取得秦罡死亡時的殘像，發布截界者通緝令。

### 情緒轉折

兩群人沒有消除仇恨，卻第一次知道對方也曾被界主當成資源。

### 章末

通緝令附著的界力殘像在青崖城上空展開，映出秦無漏的臉。
