# 第七十二章：無籍之舟

「虛舟盟不賣活界。」

顧寒生把紙鳶取出的舊盟印壓回桌上。

印只有半枚，邊緣被火燒得發黑。它屬於一艘二十七年前失蹤的分舟，舟上四十三人，無一歸航。只要在殘缺處補一道新紋，萬界城便能暫時成為那艘船的延續。

「不賣。」紙鳶說，「但會帶貨。」

「青崖巡舟若把四萬人當成貨呢？」

「那就看我們能不能讓它只看見一個艙。」

秦無漏坐在議場下首。這一次，他沒有坐掌界人的位置。青崖訊標會記錄權力流向，一旦發現萬界城由單一界主控制，偽裝便先破了一半。

沈季年把能公開的身分鏈逐項念出：秦徹留下的航誌、顧寒生的盟內識別、紙鳶的斬影刀、二十七名獲救證人的口供，以及那片會回應上一紀元格式的遺界門片。

每一件都是真的。拼在一起，卻會導向一個不存在的身分。

「無籍分舟，舟名萬界。」顧寒生冷聲道，「真假摻半，比一句假話更容易騙人，也更容易讓盟裡的人追殺。」

「所以期限七日。」秦無漏說，「只用來取得入城資格。七日後無論有沒有糧，盟印撤銷，所有交易和債務以萬界城本名承擔。」

議場沒有立刻投票。

城外，裂帶風暴又刮過一次。新土上的灰光成排伏低，像一片被看不見的風吹彎的草。眾人都知道七日不是從容，是最後能承擔的謊言長度。

表決最後以四票通過。顧寒生投反對，卻仍親手在盟印上補了辨偽紋。

「我留下記號。」他說，「若你七日後不撤，我會先替盟裡拆穿你。」

「應當如此。」

紙鳶把半印按進虛舟界門。門框立刻向外生出一層薄殼，將萬界城的山河折成貨艙輪廓。城市心臟每跳一次，外殼便跟著鼓動，看上去像某種裝了太多活物的獸腹。

青崖巡舟在兩個時辰後出現。

那是一條倒懸的黑船，帆長在船底，七名巡吏的臉都蒙著秤布。他們沒有登城，只拋下一條白色長廊。

廊上刻滿細密刻度，從人口、土地到法則壽命，一項項往下稱。

「報貨。」為首巡吏說。

紙鳶立在界門前：「死界殘土，混居器官，無籍舟民。」

「人數。」

「四萬二千一百一十六。」

秤布下的頭顱同時抬起。

長廊驟然變紅。

【活口四二一一六。】

【有議約，未見核主。】

【判類：活界貨艙。】

方折的手按上刀柄。城牆後，三千守卒已分散站入錨點，只等秦無漏一句話。

巡吏卻沒有拔兵器，只伸手指向遲影。

「貨艙可入，須留一錨。無名者最佳。」

遲影站在秦無漏身側，影子比身體慢了一步。補天院拒冊之後，青崖城顯然也看見了那道不存在於外界名冊的空缺。

「我有名字。」遲影說。

巡吏的秤布毫無波動：「外界無冊。」

「萬界城有。」

「青崖不認。」

遲影回頭看向秦無漏：「我留下。」

「不是你自願就可以。」

「那你要全城再餓一夜，證明你從不拿任何人冒險？」遲影問，「我有影縫，真要走，比你們都容易。何況他們要的是無名錨，我偏要讓這座城替一個有名字的人負責。」

議場緊急表決時，遲影給自己的授權加了三個條件：不得抹除、不得複製、每日須由萬界城名冊回應一次。任何一項中斷，影縫便自行撤錨。

青崖巡吏讀完，第一次停頓。

「條件多，押價減半。」

「人不是押價。」遲影道，「你若不懂，就記我難賣。」

她一步踏上黑船，腳下沒有投出影子。六道影縫卻悄悄留在界門內側，像六根繃緊的線。

巡舟放行。

秦無漏與紙鳶登上白色長廊。廊門在身後合攏，只剩容一人一影的寬度。萬界城所有景象被折進牆內，聽不見，也摸不到。

他試著喚殘核。

眉心只閃了一下。

【秤界廊：掌界權限禁用。】

前方黑暗裡，一架巨秤慢慢亮起。左盤放著兩日糧，右盤空著，盤底卻刻著萬界城的輪廓。

一個聲音從秤後傳來。

「無籍之舟，先稱你們四萬二千條命，值不值得進城。」
