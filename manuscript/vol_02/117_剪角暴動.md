# 第一百一十七章：剪角暴動

照影亮起時，剪角刀正從看籠人的下巴拔出來。

血濺在牆上。一個額前裹著濕布的女人踩住屍體，將那把帶鋸齒的刀換到右手。她身後有人撞門，鐵條一根根變彎，昨夜貼上去的補剪令被踩進泥裡。

秦無漏放下沒喝完的水。

城內晨糧還沒發完，方折的藥桶道核路回報也尚未送到。眼前這場殺戮，已經開始了。

「你叫他們動的？」棚外有人問。

秦無漏沒回頭。他看見女人從死者腰間扯下役牌，重重摔在地上，舉刀便砸。

「先別砸！」

棘蘿立刻翻成族語，另一側卻聽不清。隔著幾重轉接，鐵門被撞開的轟響蓋住所有聲音。

角刀落下。

役牌裂了，連在籠底的黑線卻沒有斷。它們一齊繃起，將幾個撞門的人拖倒。女人的膝蓋砸進泥裡，手還攥著刀，頸側已浮出一道越收越深的青痕。

更遠處，一根命種被人從土裡拔了出來。

整片屋棚同時歪斜。

秦無漏看見屋內伸出許多隻手，有的去扶柱，有的去抱孩子。下一瞬，光線往下沉了一截，那些手全落出照影。

他左掌的傷口被桌角撐開了。

「把聲音只送她那一口。叫她看牌底。」

紙鳶切掉相鄰兩道亂訊，棘蘿再說一遍。女人終於聽見，伏在泥裡將碎牌翻過來。底下仍纏著完整的役線，正沿她腕骨往上爬。

「鬆刀，去壓住那個側齒。」秦無漏指給她看，「先讓收緊停下。」

女人用刀尖撬進側齒，猛地壓住。

她倒吸一口氣，頸上的青痕停了。門邊有人爬起來，更多人沒有動。

她抬頭時，眼裡沒有獲救的喜色。

「昨天死一個，今天還要補剪一排。」棘蘿將她的話譯出，「等你們的門，要等到什麼時候？」

秦無漏把昨日已失效的操作牌放到照影前。

「它現在開不了門。你那裡還有誰會推承托架？」

女人轉頭喊了一聲，兩個人從塌棚旁跑來。其中一個背上插著短弩矢，他自己摸不到，便任由它晃著。

「有。」

「把活人的架先護住。你們要拿哪一段路，自己定。我能把卸扣的順序送過去。」

女人喘了片刻，將刀留在側齒上，站起身。

「拿藥道。再拿秤臺。」

她指著秦無漏，補了一句。

「傷者給你。人還能站著的，聽我們自己的。」

「接得住的傷者，我接。」

方折這時帶回核路的兩名守卒。藥桶道仍通向外側卸藥臺，中間一道小門能過人，不能過整片土地；內側守衛尚在，秦無漏手上也沒有開門權。

地圖擱進照影，女人只看了一眼，便喊人去取藥桶，自己拔起那把角刀。側齒由另一個人用鐵楔壓住，沒有跟著鬆開。

秦無漏看著那隻被役線磨破的手，知道這一區還未穩。

泉邊送來封口無異常的回報。他將回報壓下，沒叫任何守墓者起來接訊。已留的傷頻只是尋找舊線的提示；能接上的，仍須對過當下的人和事。

他讓紙鳶把照影玉的留影分成幾段，一段只演先承托、再卸扣，一段標仍不能拔的命種。各口的傳話人自行核對，答得上的才往下傳，答不上的就留空。

很快，一面沾滿血手印的木板出現在光裡。

女人把它掛在秤棚下，讓不同籠區來的人各留一塊碎瓦。哪條路通、哪一口缺人抬架，都有人站在板前叫。幾個人爭得面紅耳赤，最後決定先護藥道，暫不追逃向高臺的看守。

那是他們自己排出的順序。

秦無漏把城內接應位對到藥道出口，讓方折核定這一次的人手。前一日的授權已結束，這回只送護藥臺的人、醫包與搬運器具；傷根不再用，城市心臟照常供著城內六萬多口人的晨食。

棘蘿帶來幾名願意去外臺的族人，將還能出力的範圍指給方折看。有人只能護到一輪換藥，有人只答應抬傷者，方折在他們肩上分別繫了布條，沒有混成一隊衝鋒。

「秦無漏！」照影裡有人在罵，「你有一座城，才出這幾個人？」

他抬眼看向聲音所在，那邊正有人抬著折斷的屋梁找親人。

「這幾個人去護藥臺。要我再接一口，先把哪裡能接告訴我。」

對方又罵了一句，卻伸手指向一條窄縫。

秦無漏讓紙鳶記下。

藥桶道的小門在不久後被推開。

先滾出兩個空桶，後面跟著一具穿看守短甲的屍體。門內有人將當值門牌插回槽裡，示意別碰最後一根承托梁。秦無漏讓紙鳶把宿主舟移到既有外臺能接近的位置，方折從舟上跨過木板，踩到實實在在的卸藥石面。

兩側終於接上。

醫包先過，受傷的人被抬到原牧場外臺的遮棚下。這裡離萬界城的門還有一道轉運，暫留在當地救護，不因鋪了城裡的布便算已經入城。

背上中矢的搬架人把第一副擔架放下，才肯坐下讓人看傷。旁邊一個孩子始終攥著母親的袖口，醫者翻到她頸側，看了很久，最後替她蓋上布。

秦無漏站在舟邊，聽見孩子問，為什麼不搬她。

醫者說，她已經死了。

外臺陸續抬出幾十具遺體，還有更多被埋在倒塌的籠棚內。傷亡沒有清完，從哪一區來、是否已辨姓名，先分開掛牌。沒有人能把這場暴動抄成一列整齊的勝績。

棘蘿將一杯水放到秦無漏左手邊。

他沒拿。對面秤棚又亮了。

持刀女人帶著幾個搬架人，把一名活捉的看守按在操作槽旁。看守指向中央線，說主印還在，哪怕殺光此處的人，牧律也會把他們全收回去。

「聽見了？」女人對著照影問。

秦無漏看見槽裡的東西，卻與看守的話不同。

承托架已頂住，生活區沒再下沉；放貨牌插在原槽，幾條日常供力線已沿交割程序移到本區保留的承托上。只有接往中央的一束強制牽引仍繃著。

昨日他們卸了這些線，留下空扣環，門便能關回去。

今天這些人想把關回去的手也砍掉。

「先驗空。」秦無漏說。

他讓當地搬架人按各自熟悉的槽位逐條核對，用已知時序將強制牽引卸入空側。新的圖由對方照來，殘核只比較秦無漏能接觸到的外臺法則與已見結構，沒替他看穿其餘牧區。

最後一條線離開住人的那一側，回扣上的暗光熄了。

女人把角刀抵上去。

看守往後縮，忽然大喊那是祖家的器物，毀一枚，整族都賠不起。

女人扯住他的衣領，將他拉到空槽邊，讓他看清楚。

「你數。」她說。

刀背落下，第一枚空扣環斷了。

第二個搬架人舉起鐵錘。

第三聲從另一道照影裡傳來。

高臺上的看守還在喊跪下。靠近門口的一名老者立刻屈膝，動作比命令結束還快，直到膝頭撞上碎環，才茫然地看著自己的手。

女人沒有罵他，將一柄從看守身上卸下的短錘放在他旁邊。

老者摸了摸額前那塊平滑的舊疤。角沒有長回來，聽見喝令時，身體也仍會發抖。他扶著門柱站了兩次，第二次才站穩，彎腰拾起短錘，去幫旁邊的人壓承托楔。

秦無漏把這一幕留在眼前，沒有叫紙鳶替它配上任何話。

幾個人開始撿短弩、拆箭匣，把能用的兵器放到木板下。壞掉的役牌另堆一處，沒拿來換糧，也沒交給某個人重新保管。棚裡少了看守的鞭聲，多了搬架人一聲一聲喊住別急。

秦無漏面前幾條中央牽引先後熄滅。先前拔命種的區域仍陷在灰暗裡，沒有因此復原；守住承托、解清線再毀空環的幾處，卻不再隨高臺的收令收縮。

一根役索被高高提起。

它抓回去的只有斷鐵。

「再收啊。」女人朝高臺說。

看守趴在地上，沒有再報祖家的名字。

中央牧律第一次缺掉了幾段能真正落到人身上的連接。

那幾處並沒有變成新天地，生活仍靠原地承托維持；卻已能自行護住已開的小門，選擇接誰、送誰，或把想逃回高臺的看守截在路上。

秦無漏將桌角昨日的真操作牌收進布袋。這枚牌完成過一次用處，再開下一道門，要靠眼前這些人握住的新槽。

他向女人報出能接的醫包和下一輪擔架數。她點頭，轉身去處理木板前的爭執，沒有向他請示接下來該打哪裡。

遠處忽然響起沉悶的舟角。

紙鳶的手從照影玉上抬起，指向外臺以外。雲灰裡升起三種不同的舟旗，最近的一列船頭已有補天院的尺紋，另一列獵舟正放下收貨鉤。

牧場高臺上的守衛重新列開。

秦無漏看著三面逐漸合攏的光，將剩餘的日帳攤到乾處。

牧律少了幾條線，來收線的人到了。
