> **「世間萬物皆隨時日損耗，唯有將界域煉至『無漏』，方能超脫界歸赤字。」**

《無漏》是一部東方玄幻/界域流長篇小說作品。本專案包含完整的作品世界觀聖經、人物勢力設定、分卷細綱、伏筆台帳、正文章節，以及專屬開發的 **Web 互動式線上閱讀器**。

---

## 📖 線上閱讀器 (Web Reader)

本專案內建專屬開發的高質感 Web 閱讀器，支援電腦與行動裝置：

👉 **[點此直接開啟《無漏》線上閱讀器](https://skydreamer0.github.io/novel_world_without_loss/)**

### 閱讀器核心特色

- 🎨 **現代視覺與雙主題**：支援日光（Light）與暗夜（Dark）主題，極致的排版體驗與動態微動畫。
- 📚 **目錄導航與自然排序**：自動解析章節序號，分目錄展現正文、細綱與設定集。
- 🔍 **全文搜尋與章節過濾**：快速搜尋關鍵字與章節內容。
- ✍️ **劃線與批註系統**：支援文本選取高亮與個人筆記儲存。
- 🔊 **語音朗讀 (TTS)**：內建 Web Speech 語音朗讀引擎，可自訂語速與朗讀起點。

## 🛠️ 本地開發與使用 (Local Development)

若您想在本地執行或調試閱讀器：

1. **複製專案**：
   ```bash
   git clone https://github.com/skydreamer0/novel_world_without_loss.git
   cd novel_world_without_loss
   ```
2. **開啟本地 HTTP 伺服器**：
   ```bash
   # 使用 Python
   python -m http.server 8000

   # 或使用 Node.js / npx
   npx serve .
   ```
3. 瀏覽器造訪 `http://localhost:8000` 即可開啟閱讀器。

## 📜 寫作規範與設定權限

為維持長篇小說設定的嚴謹度與連續性，專案遵循以下權限優先級：

1. 已確認的作品聖經（`docs/02_世界鐵律.md` 等）
2. 已確認的分卷路線圖（`docs/05_分卷路線圖.md`）
3. 已確認的章卡（`outlines/`）
4. 既有正文（`manuscript/`）
5. 臨時提案 / 草案

同級內容衝突時，以較新的確認版本為準；不得自行修改核心鐵律或世界真相。
